# 需求：未来 NPC 互动和历史事件响应

Status: draft

## 需求

NPC持久存在，Agent按需唤醒；历史事件保存事实，必要时被相关NPC或剧情Agent引用。确定性后果仍由游戏规则直接执行。

## 范围

后续事件路由、知情范围、互动会话、发言顺序和游戏裁决。世界事实、NPC认知、消息转述分开；同一事件可以影响多个角色，不为每个事件常驻一个Agent。

## 验收

- [ ] 最小后续演示：村民向师父转述行善，师父只在消息到达后知情。
- [ ] 循环互动受轮数/预算/结束条件限制。
- [ ] 冲突行动由游戏裁决，Agent不能直接改写世界事实。

## 当前进展

2026-09-17：有限动作选择、事件投递和NPC行为树的最小范围由[需求018](018-behavior-trees.md)及其前置015～017承接，详细v1已确认并实施。本需求其余互动会话范围仍为未来工作，不随此次自动批准。

015/018已提供持久事实事件、有限NPC唤醒与反应；多人互动会话、转述认知与发言顺序仍未实现。

## 待完善
