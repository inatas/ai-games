# 025 模型房间单一调度宿主

Status: implemented；方案 v1 已实施（2026-09-27）。

## 需求

000013 首夜女巫用药调用由仍在后台运行的旧 Docker `app` 拒绝为 `MODEL_BUDGET_EXCEEDED`，截止默认 `pass`。新版宿主机服务同时运行，说明不发布 HTTP 端口的旧进程仍能扫描同一数据库房间。人工停止旧容器后当前故障消失，但需要防止下一次双宿主启动。

## 范围

建议在狼人杀模型房间服务启动前取得同一 PostgreSQL 数据库的独占调度所有权；只有持有者能恢复房间、开新局或发模型请求。设计见[单一宿主 v1](../../mods/werewolf/docs/model-room-single-owner-v1.md)，验收见[测试设计](../../mods/werewolf/docs/model-room-single-owner-testing-v1.md)。旧版程序若未实现同一锁仍可并行；部署时必须先停用旧版并核对进程。不修改其他游戏的房间调度、不清理或改写已有 000013 存档，也不改变供应商费用控制。

## 验收

两个宿主连接同一数据库时恰有一个能启动模型调度；失去锁的宿主不得发模型请求或把房间标为失败。持有者退出后另一宿主可以接管并从持久阶段恢复，不重复已提交动作。相关并发、异常退出和恢复用例见测试设计。
