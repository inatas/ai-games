# 需求：未来自主规划与 Agent 路由

Status: draft

## 需求

未来游戏可给目标，由规划器分解步骤并选择允许的Agent或能力，复用现有Harness执行每一步。

## 范围

未来新增Harness上方编排层：任务/父子调用ID、能力注册、权限、预算、停止条件、任务恢复。当前MVP不实现，不添加空Agent类冒充能力。

## 验收

- [ ] 独立后续版本定义任务状态与中途失败语义。
- [ ] 父任务不持scope锁等待子调用；每一步独立提交。
- [ ] Agent选择也经白名单/参数/预算校验。

## 当前进展

2026-09-17：有限动作选择、事件投递和NPC行为树的最小范围由[需求018](018-behavior-trees.md)及其前置015～017承接，详细v1已确认并实施。本需求的通用规划范围仍为未来工作，不随此次自动批准。

通用多步规划器仍只有扩展方向；当前最小NPC行为循环由018实现，不能等同于本需求的通用Agent编排。

## 待完善

确定目标类型、工具权限、预算和任务补偿策略；具体实现必须作为后续需求开发，不能扩大当前MVP验收范围。
