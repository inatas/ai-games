# 有界模型网络重试

Status: proposed

## 需求与归属

000015 中部分狼人杀 SPEECH 调用约 8 秒后以 `MODEL_UNAVAILABLE`、`transportCategory=network` 失败，没有收到 HTTP 响应。需要在原游戏行动截止点内争取模型结果，同时限定额外调用和可能的 token 费用。重试判定、审计、幂等和熔断可跨 MOD 复用，归框架；狼人杀的时限与默认动作仍由 MOD 持有。MOD 接入见[狼人杀需求 010](../../mods/werewolf/.agents/note/010-model-network-retry.md)。

## 范围

### v1.1 已确认实施范围

权威协议与验收见[框架模型适配](../../docs/specs/framework.md)和[框架验收](../../docs/testing/turn-based-matches.md)。拟在 Harness 实施每个决策最多 3 次实际 HTTP 调用的总额度：首次调用后仅对符合条件的网络失败最多重试 2 次；格式纠正共享总额度，不能叠加调用次数。每次网络重试都必须在上次调用确定失败且失败日志持久化后，等待独立的退避间隔，不能立即重发或与前一次调用重叠。保留现有 requestId、阶段截止、租约和最终事务重验，增加每次调用独立 attempt 审计与熔断诊断。重试策略由受信任服务端配置，默认不启用；狼人杀显式启用。

不包含跨供应商切换、无限重试、延长游戏阶段、估算失败调用 token、供应商侧去重保证或恢复一个供应商已生成但本机从未收到的响应。无数据库表变更；日志 JSON 字段随实际 attempt 扩展。

## 当前进展
