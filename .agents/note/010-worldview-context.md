# 需求：公共世界观配置与固定上下文

Status: implemented

## 需求

框架加载基础世界观配置，每次模型调用均包含完整世界观。加载和注入为公共能力，不能只实现在武侠Quickstart中。

## 范围

服务端WORLD.md加载、不可变版本存储、scope关联、必需上下文预算及调用追溯。具体题材文字由游戏提供。详见[设计](../../docs/specs/accounts-worldview.md)和[测试设计](../../docs/testing/accounts-worldview.md)。不提供玩家编辑器、旧局自动版本升级。

## 验收

- [x] W-01至W-03：每次调用与纠正均注入，预算及规则边界有效。
- [x] W-04至W-06：配置校验、版本持久化和scope隔离。
- [x] W-07至W-08：无AI动作不调用模型，调用可追溯版本。

## 当前进展

公共加载器、不可变世界观版本、scope关联、必需上下文注入和调用追溯已实现。中性世界观测试与全量28组Docker回归通过；见[验证记录](../../docs/verification.md)。
