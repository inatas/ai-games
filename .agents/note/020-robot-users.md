# 020 Robot用户目录

状态：in_progress。用户已确认Robot为具有独立userId的用户，并明确要求按沟通结果产出工具与robots、先写note再开发。

范围：项目根robot-users/users每用户JSON及assets素材目录；默认12个独立UUID用户、昵称/性别/头像/立绘、固定初始人格和随机脚本控制配置，固定句子发言。共享模型profile为未来引用，本轮不调用模型、不实现人格生成。配置不保存登录凭据、资产、好友或对局记忆。身份UUID与现有用户标识形式一致；未来账号/社交落库另行接入，本轮不伪称已注册到真人账号数据库。

实现：应用服务端加载并严格校验目录（唯一ID、资料、受支持控制器、素材边界），对客户端只投影公开资料；MOD接收类型化用户阵容，不能反向读取根配置文件。用户目录不含狼人杀身份，身份在开局分配。资料快照随本局保存，换座后头像和昵称按用户保持。

游戏集成及工具见mods/werewolf/docs/robot-seating-v1.md及该MOD需求001。目录加载测试覆盖重复ID、非法控制配置、素材路径和公开投影。当前仅本地无模型演示，目录定义持久、对局内存不持久，不新增正式登录/房主权限。
