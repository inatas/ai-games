# 青溪配置运行接入 v1（已确认并实施）

依赖[框架设计](../../../docs/specs/configured-game-runtime.md)，不复制其协议。此次仅迁移已有青溪内容和规则，门派、战斗、成长、奖励数值与角色属性005均不改版。

地图及NPC静态定义迁入本MOD JSON；出生位置只用于realm初始化。已有通行资格通过本MOD注册规则函数引用，地图投影和共同move使用相同判断。已有角色行动改接Action入口，保留原业务校验与结果。物品和任务必须原子发生的变化仍在原事务执行。

首版自主巡逻与模型选择示例放框架中性测试MOD，青溪既有NPC默认不配置行为树，以免未经游戏设计改变护送或任务位置。之后若要让青溪NPC巡逻或响应剧情，需在本地另行明确角色、路线、条件与玩法验收。

接入验收QCR-01：相同角色状态和输入，迁移前后通行、动作结果、数值和奖励一致。QCR-02：重启不重置NPC、角色位置或库存。QCR-03：既有护送/共享任务的NPC位置和并发判定保持。QCR-04：浏览器不暴露隐藏地图条件与内部事件。可执行测试归mods/qingxi/tests；验证见[框架记录](../../../docs/testing/configured-game-runtime-verification.md)。
