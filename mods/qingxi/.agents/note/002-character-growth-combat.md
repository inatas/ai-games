# 需求：角色成长与确定性战斗

Status: in_progress

## 需求

在现有房间世界中加入可持续角色档案、两条门派成长路线、消耗潜能的学武、可重复师门任务及服务器权威的回合制战斗，形成“任务→成长→挑战”的最小闭环。

## 范围

用户于2026-09-16确认架构调整并要求执行002和003。v3包含角色名称/性别、气血/内力、经验/潜能、门派与技能；青松门和百草门各一名师父、一门基础技能和一门门派技能；师门任务、一个恶徒、普通攻击与一项技能、轻量死亡恢复。数值、资格、伤害、奖励和死亡由游戏引擎确定性计算；AI只生成受约束的NPC态度与叙事。

以上为已确认范围。

设计、数据与接口见[成长与共享江湖v3](../../docs/v3-growth-social.md)，测试契约见[v3测试设计](../../docs/v3-testing.md)，执行顺序见[v3实施计划](../../docs/v3-plan.md)。

## 验收

- [ ] CG-01～03：角色创建/旧档补全、拜师与技能学习。
- [ ] CG-04～07：师门任务、战斗、死亡恢复、奖励幂等与并发。
- [ ] CG-08：AI不能修改伤害、经验、潜能、掉落或资格。
- [ ] CG-09：刷新、重启和新局语义正确。
