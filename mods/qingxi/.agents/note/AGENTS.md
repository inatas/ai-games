# 青溪镇 Agent Notes

本目录继承[项目开发规则](../../../../AGENTS.md)、[通用 Note 生命周期](../../../../.agents/note/AGENTS.md)及[青溪镇 MOD 指引](../../AGENTS.md)。青溪镇专属的新独立 feature 使用本目录下一个三位序号；同一 feature 续写原 note，并同步[本地索引](README.md)。

`Status:` 仅用 `proposed`、`implemented`、`rejected`、`archived`，含义与迁移条件以通用 Note 生命周期为准。游戏设计与验收更新已有 MOD 文档和测试契约；跨框架能力另建根 note 并相互链接。实际验证不足时保持 `proposed`，不能把待用户确认或待真实模型验收写成已完成。
