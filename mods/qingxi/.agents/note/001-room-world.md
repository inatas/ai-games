# 需求：房间驱动的武侠世界 MVP

Status: implemented

## 需求

参考侠客行MUD以房间、人物、物品和行动组织世界的方式，将现有四动作Demo扩展为可探索、可交互、可持续保存的Web武侠示例。采用原创小区域和人物内容，不逐房间制作背景图。

## 范围

v2已由用户“继续代码实现”确认并实现，替代v1草案。包含职责边界、B/S呈现、12个房间、5名NPC、L2节点地图＋轻量L3三类场景模板、物品背包、一条任务、基础成长、有限AI判定和存档兼容。默认每用户独立世界实例；L1战略图、势力/天气、自主Agent、自动寻路、推送和地图编辑器均暂缓。

设计与接口、数据契约见[武侠世界MVP设计](../../docs/world-mvp.md)，验收与夹具说明见[测试设计](../../docs/world-mvp-testing.md)。公共上下文扩展关联[框架011](../../../../.agents/note/011-composable-game-context.md)，其v1仍待单独确认；本需求不改变公共协议。

地图投影、信息边界及交互见[地图表现设计](../../docs/map-presentation.md)，版本回退使用需求记录中的 Git 检查点。
