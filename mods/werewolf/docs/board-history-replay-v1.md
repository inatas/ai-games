## 页面结构

保留现有头像、中央发言气泡、昼夜过场、墓碑公告和持续倒计时。中央公开记录改成按**公开发生顺序**排列的简明时间线，不再逐条镜像所有事件：

```text
当前：第 2 天白天 · 放逐发言
──────────────────────
第 1 天白天
  警长竞选票型：8号 ← 1、3、5号…
  8号当选警长
  第1夜结果：平安夜
  放逐票型：12号 ← 1、6、9号…
  12号放逐出局
第 2 天白天
  第2夜结果：3号、11号出局
  当前阶段：放逐发言（倒计时照常运行）
──────────────────────
左下：〔书本图标 历史〕
```

中央保留公开的重要结果：夜间公开死讯或平安夜、警长选举票型及结果、放逐票型及出局、警徽流转、公开翻牌、猎人开枪、自爆、终局结果。按事件所在白天分组；第1夜结果在第1天**警长竞选之后**出现，后续夜晚结果在下一白天公布，不在夜间提前显示。发言期间的中央气泡继续实时展示当前发言正文，但中央记录不再生成“已发言/已留遗言 · 内容见历史”“发言顺序”行；所有发言与遗言进入合并面板。未识别或内部事件不生成占位文案。主记录保留有限高度与滚动，标题始终表示现场阶段；时间线有明确“第N天白天”和“第N夜结果”标签。

## 警长票型的公开时机

警长投票尚未结算时，任何旁观视角均不能取得单人的选择或中间票数。完成一轮警长投票后，由狼人杀MOD一次性追加公开汇总事件 `sheriff-votes`，包含轮次（常规/PK）、每名投票者最终投向或弃票/未投、候选人票数、当轮最高/平票结果；此事件须排在对应 `sheriff-pk` 或 `sheriff-result` 前。现有逐人 `sheriff-ballot` 仍保持赛后可见的原始审计记录，不在公开API中提前露出。PK轮另出一张票型；仅一名候选人自动当选、无警长票的房规或自爆流失警徽时显示结果及“无投票”，不伪造票型。警长票每票1票，放逐票才有警长1.5票。共用票型展示组件，但标题、权重与结论按选举/放逐分别表达。

这个新增公开事件是MOD业务事件，不扩展通用回合框架接口；服务端现有公开事件投影、终局回放投影与UI按序接收。已有完成的历史房间没有这条新汇总事件时，中央仍显示警长结果，不从赛后私密逐票数据反写公开历史。新开的房间具备完整票型。

## 合并面板

全局只保留左下一个“历史”入口；终局沿用此入口，面板标题改为“对局复盘”，删除底部独立“复盘记录”按钮和原始事件列表。原来的“查看身份”按钮可继续独立展示终局身份。面板宽度随牌桌缩放，最大不超过当前牌桌宽度，手机和桌面均在牌桌内留边；材质沿用木纹框、深青背景与羊皮纸气泡，不出现纯色大块或金属亮面。

面板顶部固定标题、天数切换和现场状态；中部单一滚动时间线，按真实事件顺序穿插阶段标题、玩家头像/座位/完整发言气泡以及**已结算**的警长与放逐票型。气泡字号由当前16px略降至约14px，行距保持可读，长段落自然换行不截断，头像保持现有小尺寸。票型仅展示一份汇总，不在其下重复逐票表格、总票表和“查看详情”。“公开结算记录”、所有未识别事件占位、重复出局/投票叙述、夜间私密动作逐条原始日志均不进入此阅读面板。

局中面板只消费公开 `events` 与 `speeches`，不读取 `replay` 和 `roles`；切换公共旁观/席位视角不会让该面板泄露额外秘密。终局面板展示整局所有天的完整公开发言和票型，并可展示终局已揭晓的身份；不罗列狼刀、用药、查验等技术原始记录。终局完整私密回放仍由现有后端DTO保留供后续功能使用，本版只是删除面向用户的原始日志呈现，不删除服务器数据。查看历史期间游戏、倒计时和新事件继续更新；当前滚动位置不被新内容抢走，切换天数或关闭重开按既有交互重置。

## 数据、边界与实施

除新增 `sheriff-votes` 公开汇总外，沿用 `DemoSnapshot.events/speeches/replay/roles`，无数据库迁移、模型调用、计时或裁判胜负变化。警长投票结算与事件追加必须在同一次状态转换中完成；重复执行、恢复或轮次跨夜不能重复公开、把未结算票暴露出来，或错配到下一轮。第1天夜死仍晚于警长结算公布。前端只按事件序号和日次构建展示条目；事件原始数据不因UI删除而丢失。既有公开记录和历史发言的持久事实保持可查。

实施顺序：在需求note记录确认范围；整体界面调整前按项目规则建立本地Git检查点，明确暂存现有工作树且不包含本机秘密/日志；先补可失败的MOD警票公开时机与纯前端时间线/权限/宽度验收测试，再实现选举事件和UI；更新旧的相反文档断言，运行定向、类型、仓库、单元、构建及可用的集成测试，最后用运行中的游戏和终局房间在手机/桌面宽度目视核对。

验收重点：

1. 首夜竞选前无夜死和警票；正常警选结算后先显示警票/结果，再显示真实夜死或平安夜；单候选、PK、弃票、全弃票、自爆无票均准确。
2. 中央存在“第N天白天”“第N夜结果”；不出现发言顺序、发言/遗言“内容见历史”、未知事件“公开结算记录”，终局与局中都不回退。
3. 局中合并面板仅有已公开发言和票型；终局可查完整各日发言、票型与已揭晓身份，没有逐条原始结算/夜间私密日志；票型不重复。
4. 390×844与1280×900窗口中面板不超出牌桌左右边界，14px左右正文能读完长发言；面板打开时倒计时与游戏继续运行。

待用户确认的理解：这里将“完整复盘信息”解释为**完整公开发言、各轮票型和终局揭晓身份**；用户要求去掉的“其他记录”包括原始夜间动作日志。若用户希望终局仍看到狼刀/用药/查验，请在确认时指出，应改为单独的赛后私密页签，不混入发言时间线。
