# 死亡覆盖v3.1生成记录

工具：内置 imagegen，编辑模式。

参考：death-states-v3.png为重做对象；用户三张截图为图形与手绘风格参考；ui-v2-implemented.png为现有游戏风格参考。

提示词要求：横版3×2六枚同尺寸不透明圆形头像覆盖图。完全禁止文字、数字、标题、标签、座位号底片、头像外框、金属环。六枚均用深褐#30221E纯色底，浅棕和赭色平面填色、略不规则深棕手绘轮廓，统一线宽与视觉占比；禁用立体、浮雕、金属光泽、投影、渐变、材质纹理及装饰。上排束缚双手、骷髅（替代出局文字）、自爆烟团；下排单弹孔、三道斜爪痕、木塞毒药瓶。弹孔无枪，爪痕无刀，药瓶无骷髅或标签。不出现人物或游戏界面，圆底完全遮盖头像，图外为纯色青灰背景。

输出：death-states-v3.1.png。生成图有轻微底纹，记录为效果图限制，正式素材需纯色化。
