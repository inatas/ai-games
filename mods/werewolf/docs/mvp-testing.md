# 狼人杀MVP验收方向（待细化）

依据[大纲](mvp-design.md)，规则来源已在大纲指定，后续据此补充具体用例。目前没有可执行测试或通过记录。

- 12席及阵容正确，每席模型独立配置，就绪后自动开局。
- AI按规则自主发言、行动与投票，服务端权威结算。
- 实际模型输入只包含该角色有权获知的信息。
- 对局中旁观者仅见公共信息，浏览器响应中也不存在隐藏信息。
- 正常结束后可查看真实身份及完整行动记录；暂停不提前揭密。
- 页面只读，日夜、座位、发言和公开票型清晰。
- 重启恢复、重复提交和模型失败不造成重复行动或部分结算。
- Mock行为测试、真实数据库和真实模型完整对局分别验证并记录证据。

本次新增验收方向：

- 竖版布局左右各6席、固定座位号，中央文字可读；桌面居中，窄屏及低高度屏可滚动阅读。
- 隐藏身份不影响头像、装饰或夜间高亮；公共进度不暴露具体神职调用及座位。
- 依指定规则验证禁止连续查同人、女巫不能自救或同夜双药、猎人中毒/最后神职禁枪、白痴翻牌失票及夜间顺序。
- 警长、双爆吞警徽及其未展开细节在详细设计后补全测试，不沿用撤回草案的默认行为。
