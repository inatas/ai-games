# 狼人杀本机模型测试台 v1.1 验收说明（已实施）

关联[设计](web-model-test-v1-1.md)。接口测试与本机部署检查已执行；网页人工复核仍待用户操作。

| ID | 场景 | 通过标准 |
|---|---|---|
| WW-L01 | 页面免口令 | 本机模式打开、刷新、重新进入座位管理和模型诊断均无测试口令输入，profile 可直接加载 |
| WW-L02 | 付费开局与诊断 | 本机模式可选择已配置 profile 开局、看私有席位视角和逐次调用详情，原有幂等与授权事实投影保持一致 |
| WW-L03 | 本机范围 | Compose 宿主发布端口仅绑定回环地址；未启用本机测试模式时付费开局和私有诊断被拒绝 |
| WW-L04 | 凭据装配 | Compose 从专用用户文件注入所需环境变量；缺必需变量时模型服务启动失败，不能默默改为脚本 Robot；宿主端口由 Compose 固定绑定回环地址 |
| WW-L05 | 不泄漏密钥 | 仓库、前端构建、公开目录、API 响应、房间和日志均不含供应商 Key；服务端调用仍成功 |
| WW-L06 | 兼容已有房间 | 旧房间 ID、profile 绑定、公开回放和持久诊断数据可继续读取；不迁移或清除历史记录 |

接口行为测试先失败，实施后通过；Compose 配置、启动和宿主端口已检查。本机浏览器人工验收与真实新局仍待用户执行。
