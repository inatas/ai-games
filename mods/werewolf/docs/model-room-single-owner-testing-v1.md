# 狼人杀模型房间单一调度宿主 v1 测试设计

状态：v1 已实施。关联[设计](model-room-single-owner-v1.md)。

| 用例 | 预期 |
|---|---|
| SO-01 同库双宿主 | 首宿主持锁；次宿主明确失败，不能扫描房间或产生模型调用 |
| SO-02 异常退出接管 | 首宿主连接断开后锁释放；新宿主取得锁并恢复同一房间，已提交动作不重复 |
| SO-03 不同数据库 | 各数据库可独立持锁运行，不互相影响 |
| SO-04 启动顺序 | 锁取得前不开放开局、恢复或付费请求；未取得锁不写游戏失败状态 |
| SO-05 关闭与并发 | 正常关闭释放锁；并发抢锁只有一个成功；模型等待不占用数据库事务 |
| SO-06 旧版切换 | 记录旧镜像不遵守新锁的限制；按停旧实例、核对单宿主、启新版的顺序演练，不宣称新锁能阻挡旧镜像 |

旧行为下，同库第二宿主测试先失败（它错误地成功取得服务）；实现后隔离 PostgreSQL 测试库中的 5 项所有权测试通过。涵盖同库排他、异常断线后的接管、不同数据库、应用启动顺序与并发抢锁；既有持久房间测试验证重启与动作幂等。完整测试 267/267 通过，类型、仓库检查和构建通过。部署前确认开发库没有运行中的模型房间；停旧版再启新版，网页及健康接口为 200，数据库该键恰好一条已授予锁。未调用真实供应商，也未在开发库强制断开持锁连接。
