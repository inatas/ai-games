# 行动截止与默认结算 v1

归属：狼人杀MOD游戏规则，不属于模型输出策略。2026-09-22用户明确：超时默认动作应为游戏流程的标准判定，不论参与者是否为大模型。2026-09-23用户确认整张默认动作表；以下为本项目规则，不宣称不同平台均采用同一标准。

## 统一判定

人类、模型、固定脚本、随机脚本共用相同阶段截止点和裁判接口。在截止点之前收到合法动作则按规则接纳；到期仍无合法动作，裁判对该席执行该场景的默认结算。模型错误、断线或格式错误只是未取得合法动作的原因，不另设模型专属默认规则，也不因提前请求失败就提前结束阶段。合法重提若规则允许仍受同一截止点限制。

| 场景 | 本项目确认的默认结算 |
|---|---|
| 发言/遗言 | 结束该次发言权，系统标记未发言，不替玩家生成正文 |
| 狼刀 | 未提交者空刀，合法已提交保留；空刀不参与平票抽选 |
| 预言家查验 | 从当前合法目标中按本局种子确定性随机查验；模型与脚本席位使用同一裁判规则 |
| 女巫 | 不用药，不消耗药量 |
| 上警 / 退水 | 不上警 / 保持竞选 |
| 警长与放逐投票含PK | 弃票 |
| 猎人 | 不开枪 |
| 警徽移交 | 撕徽，警徽流失 |
| 发言方向 | 逆时针 |
| 自爆 | 没有独立超时；未提交就不自爆 |

异常来源在服务端审计区分，公共界面只显示该阶段规则要求的信息；夜间不得通过异常提示泄漏角色。默认提交和普通提交互斥、幂等、同事务；数据库/规则异常不能伪装成默认成功。恢复仍使用原deadline，不重新给予完整时间。

测试应覆盖同场景的人类命令、模型结果、脚本结果到期时得到相同默认结算；模型协议测试只检查其输出合法性与请求取消，不再拥有默认动作表。

2026-09-23用户明确选择“随机查验合法目标”；本条由待裁定提案改为已确认规则。实现须保存随机状态或可重现的窗口种子，确保恢复、双宿主、重复截止扫描得到同一目标且只结算一次。

2026-09-23时限确认：普通上警及普通发言120秒；当选警长的日间发言120+30秒。其余沿方案值：PK/遗言90秒，报名/投票/猎人30秒，退水/方向/警徽20秒。夜间狼人与预言家共享60秒，女巫随后30秒；夜间窗口即使所有动作提前提交仍到固定边界结算。

追加裁定：模型提前返回原则上不缩短**任何**流程。白天单席发言、遗言、猎人开枪等也持续到各自截止；只有该席主动触发明确的“跳过本回合”操作才提前结束，当前纯Robot局无此操作。夜间总是60+30秒且不能被提前确认结果或女巫死亡缩短；女巫死亡时，狼人与预言家行动仍在第60秒封盘，随后保持30秒黑夜等待后再进入白天。运行时需区分行动截止与阶段结束时间。

## 白天Robot发言完成后3秒跳过（v1.2待确认）

用户新要求：模型或脚本Robot说完白天发言后，等待3秒统一提交“跳过本回合”。本增量拟将**合法非空发言已被裁判接纳**视为Robot本席授权发出的跳过意图；3秒从服务端成功提交时间算起，不从生成开始、UI显示或模型请求结束算起。提前返回本身仍不直接推进阶段。原120/150/90秒上限继续约束模型响应和异常兜底。

适用普通日间发言`speech`（包括当选警长的150秒发言）、上警竞选发言`election-speech`与PK发言`pk`/`election-pk`。不适用`last-words`、`shot`、投票、上警报名、退水、夜间行动或真人席位。没有合法非空发言时不自动跳过，到原截止按默认动作结算；已说完但距原截止不足3秒时，仍由原截止结束。Robot自动跳过只结束当前席位发言，不改变后续席位、夜间60+30秒或整局胜负流程。

执行时在房间持久状态保存当前阶段的提前结束时刻；宿主到点短事务核对阶段实例、发言已提交和有效时刻，再调用现有阶段结算。重复扫描、重启、并行宿主及过时定时任务不得重复或跨阶段结算。屏幕可在3秒保留说话者、发言气泡和倒计时。这个待确认增量仅替换上一段“纯Robot局无主动跳过”的白天特例，其余固定窗口规则继续有效。
