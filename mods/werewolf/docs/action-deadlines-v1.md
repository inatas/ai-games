# 行动截止与默认结算 v1

## 狼队协商截止（J2，已实施）

[015／016 联合方案 J2](model-integration-v1.md#015016-联合原则j2工程已实施真实模型待验收)的组织阶段默认如下；后续技能与白天仍用下方原默认表：

| 拟议场景 | 无合法提交／失败／超时 |
|---|---|
| 主提议 | 无提案，不编造正文／计划；剩余时间足够才补位一次。 |
| 补位 | 无替代提案，保留已有真实记录，不追加第三轮。 |
| 自刀目标同意 | 未获同意，不采用该自刀；明确拒绝或截止前终止失败且时间足够才可补位普通刀口／空刀，不再问另一个自刀目标；共同截止已到则直接进入原夜间技能。 |
| 原狼刀 | 读取有效提议后自主提交，仍按原最高票／平票及缺失票兜底；Robot 不选未经明确同意的狼人队友刀口。 |

全部组织调用共用 45 秒期限和每夜计数，不保证跑完，不延时补问；到期继续原夜间阶段。合法回复须匹配 requestId、phaseInstance／decisionEpoch 和计划版本，晚到只留真实模型调用日志。无响应不算同意，计划不等于执行；真实获救／死亡依原授权结算。授权／数据库异常保留真实错误，不伪装为默认成功。

归属：狼人杀MOD游戏规则，不属于模型输出策略。2026-09-22用户明确：超时默认动作应为游戏流程的标准判定，不论参与者是否为大模型。2026-09-23用户确认整张默认动作表；以下为本项目规则，不宣称不同平台均采用同一标准。

## 统一判定

人类、模型、固定脚本、随机脚本共用相同阶段截止点和裁判接口。在截止点之前收到合法动作则按规则接纳；到期仍无合法动作，裁判对该席执行该场景的默认结算。原技能及白天的模型错误、断线或格式错误只是未取得合法动作的原因，不因提前请求失败就提前结束阶段。队内准备的终止失败按上方规则立即续接补位／确认，仍不缩短或延长45秒共同窗口。合法重提若规则允许仍受同一截止点限制。

| 场景 | 本项目确认的默认结算 |
|---|---|
| 发言/遗言 | 结束该次发言权，系统标记未发言，不替玩家生成正文 |
| 狼刀 | 未提交者空刀，合法已提交保留；空刀不参与平票抽选 |
| 预言家查验 | 从当前合法目标中按本局种子确定性随机查验；模型与脚本席位使用同一裁判规则 |
| 女巫 | 不用药，不消耗药量 |
| 上警 / 退水 | 不上警 / 保持竞选 |
| 警长与放逐投票含PK | 弃票 |
| 猎人 | 不开枪 |
| 警徽移交 | 撕徽，警徽流失 |
| 发言方向 | 逆时针 |
| 自爆 | 没有独立超时；未提交就不自爆 |

异常来源在服务端审计区分，公共界面只显示该阶段规则要求的信息；夜间不得通过异常提示泄漏角色。默认提交和普通提交互斥、幂等、同事务；数据库/规则异常不能伪装成默认成功。恢复仍使用原deadline，不重新给予完整时间。

测试应覆盖同场景的人类命令、模型结果、脚本结果到期时得到相同默认结算；模型协议测试只检查其输出合法性与请求取消，不再拥有默认动作表。

2026-09-23用户明确选择“随机查验合法目标”；本条由待裁定提案改为已确认规则。实现须保存随机状态或可重现的窗口种子，确保恢复、双宿主、重复截止扫描得到同一目标且只结算一次。

当前各阶段时限以[阶段计时表](phase-timing-v1.md#计时表)为准。2026-09-23 曾确认普通上警及普通发言120秒、当选警长日间发言150秒、报名与投票30秒；这些数字已由2026-09-29的 v2 修订取代。默认结算规则未变：夜间窗口即使所有动作提前提交仍到固定边界结算。

2026-09-26退水规则：警上全员发言结束后，所有候选人共用一个10秒退水窗口，结束后锁定名单并投票；退水超时默认仍为“保持竞选”。全员提前提交也在窗口截止时统一结算。方向与警徽移交继续各20秒。实施记录见[需求006](../.agents/note/006-shared-sheriff-withdrawal.md)。

此前裁定：模型提前返回本身不缩短流程；白天单席阶段持续到截止，只有席位的明确跳过操作才能提前结束。夜间总是60+30秒且不能被提前确认结果或女巫死亡缩短；女巫死亡时，狼人与预言家行动仍在第60秒封盘，随后保持30秒黑夜等待后再进入白天。运行时区分行动截止与阶段结束时间。

## Robot发言不再自动提前结束（2026-09-26）

用户明确“可以把3秒换人的逻辑先删除，未来统一设计”，取代原v1.2的提交后3秒跳过策略。狼人杀定义不再启用completionDelayMs，合法发言提前提交后仍等[当前计时表](phase-timing-v1.md#计时表)规定的阶段截止；脚本Demo发言也遵守对应截止。文字显露速度、气泡关闭和历史查看都不能结束阶段。夜间60+30秒及其他默认动作不变。

通用框架可选提前结束能力保留供其他MOD使用，不因删除狼人杀策略而改变公共接口。旧存档已安排的提前截止不做数据迁移；新阶段不再安排。实现与视觉验收见观战场景v5和需求001。
