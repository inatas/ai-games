# 行动截止与默认结算 v1

归属：狼人杀MOD游戏规则，不属于模型输出策略。2026-09-22用户明确：超时默认动作应为游戏流程的标准判定，不论参与者是否为大模型。2026-09-23用户确认整张默认动作表；以下为本项目规则，不宣称不同平台均采用同一标准。

## 统一判定

人类、模型、固定脚本、随机脚本共用相同阶段截止点和裁判接口。在截止点之前收到合法动作则按规则接纳；到期仍无合法动作，裁判对该席执行该场景的默认结算。模型错误、断线或格式错误只是未取得合法动作的原因，不另设模型专属默认规则，也不因提前请求失败就提前结束阶段。合法重提若规则允许仍受同一截止点限制。

| 场景 | 本项目确认的默认结算 |
|---|---|
| 发言/遗言 | 结束该次发言权，系统标记未发言，不替玩家生成正文 |
| 狼刀 | 未提交者空刀，合法已提交保留；空刀不参与平票抽选 |
| 预言家查验 | 从当前合法目标中按本局种子确定性随机查验；模型与脚本席位使用同一裁判规则 |
| 女巫 | 不用药，不消耗药量 |
| 上警 / 退水 | 不上警 / 保持竞选 |
| 警长与放逐投票含PK | 弃票 |
| 猎人 | 不开枪 |
| 警徽移交 | 撕徽，警徽流失 |
| 发言方向 | 逆时针 |
| 自爆 | 没有独立超时；未提交就不自爆 |

异常来源在服务端审计区分，公共界面只显示该阶段规则要求的信息；夜间不得通过异常提示泄漏角色。默认提交和普通提交互斥、幂等、同事务；数据库/规则异常不能伪装成默认成功。恢复仍使用原deadline，不重新给予完整时间。

测试应覆盖同场景的人类命令、模型结果、脚本结果到期时得到相同默认结算；模型协议测试只检查其输出合法性与请求取消，不再拥有默认动作表。

2026-09-23用户明确选择“随机查验合法目标”；本条由待裁定提案改为已确认规则。实现须保存随机状态或可重现的窗口种子，确保恢复、双宿主、重复截止扫描得到同一目标且只结算一次。

2026-09-23时限确认：普通上警及普通发言120秒；当选警长的日间发言120+30秒。其余沿方案值：PK/遗言90秒，报名/投票/猎人30秒，方向/警徽20秒。夜间狼人与预言家共享60秒，女巫随后30秒；夜间窗口即使所有动作提前提交仍到固定边界结算。

2026-09-26退水规则：警上全员发言结束后，所有候选人共用一个10秒退水窗口，结束后锁定名单并投票；退水超时默认仍为“保持竞选”。全员提前提交也在窗口截止时统一结算。方向与警徽移交继续各20秒。实施记录见[需求006](../.agents/note/006-shared-sheriff-withdrawal.md)。

此前裁定：模型提前返回本身不缩短流程；白天单席阶段持续到截止，只有席位的明确跳过操作才能提前结束。夜间总是60+30秒且不能被提前确认结果或女巫死亡缩短；女巫死亡时，狼人与预言家行动仍在第60秒封盘，随后保持30秒黑夜等待后再进入白天。运行时区分行动截止与阶段结束时间。

## Robot发言不再自动提前结束（2026-09-26）

用户明确“可以把3秒换人的逻辑先删除，未来统一设计”，取代原v1.2的提交后3秒跳过策略。狼人杀定义不再启用completionDelayMs，合法发言提前提交后仍等原120/150/90秒阶段截止；脚本Demo发言也遵守同样的原截止。文字显露速度、气泡关闭和历史查看都不能结束阶段。夜间60+30秒及其他规则不变。

通用框架可选提前结束能力保留供其他MOD使用，不因删除狼人杀策略而改变公共接口。旧存档已安排的提前截止不做数据迁移；新阶段不再安排。实现与视觉验收见观战场景v5和需求001。
