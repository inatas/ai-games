# 全AI狼人杀 MVP 大纲（待确认）

归属：[本地需求001](../.agents/note/001-ai-spectator-mvp.md)。依赖[房间制回合框架](../../../docs/specs/turn-based-matches.md)。2026-09-20按用户提供的规则页及网易狼人杀竖版截图更新大纲。规则来源已指定，整体仍处设计阶段；不沿用此前已撤回的规则假设。

## 目标

狼人杀作为第三层MOD接入独立房间制回合游戏框架，与MUD共用最底层能力，不接入MUD地图、任务或NPC运行流程。创建一个12人AI狼人杀房间。每个角色独立绑定LLM，自主发言和决策。人类只旁观，不参与任何游戏操作。

## 阵容与开局

- 4狼人、4平民，预言家、女巫、猎人、白痴各1。
- 框架支持定义N个座位，狼人杀MVP固定12人。
- 服务端配置AI角色及模型，所有座位就绪后自动开始。
- 仅做单个全AI房间，不做真人入座、匹配大厅或语音。

## 游戏循环

准备与身份分配→夜间角色行动→白天公开结果与依次发言→投票与结算→下一轮，直到满足胜负条件。

规则以用户指定的[LAL预女猎白页面](https://werewolves.games/yu-nv-lie-bai/)为依据（2026-09-20读取），UI仅参考网易布局，不混用网易规则。

页面明确的规则摘要：

- 预言家查验阵营，不得连续查同一人；女巫各持一瓶解药和毒药，不可同夜双用或自救。
- 猎人中毒死亡不能开枪；作为最后一名神职出局时也不能开枪。白痴被放逐可翻牌免死，之后保留发言但失去投票权。
- 狼人夜间袭击，可自爆；好人消灭全部狼人获胜，狼人按屠边结算。
- 包含警长与双爆吞警徽。夜间顺序为狼队行动、女巫、预言家、白痴确认、猎人状态告知，再天亮。

该页未完整展开警选/平票/警徽移交、狼队目标分歧、遗言、双爆流程和同时死亡的全部判定。详细设计时整理这些空缺，不能把项目自行补充的约定写成页面原规则。当前保持大纲，不扩写完整裁判协议。

## AI信息边界

每个AI只能看到当前规则允许的信息：公开场上状态、已公开发言与票型、自身身份和操作记录，以及角色允许的私有结果。狼人额外知道队友，并按规则获得狼队信息。

AI上下文互相隔离；每个座位可绑定相同或不同LLM，但不能共享私有历史。AI负责选择行动和生成发言，服务器负责规则与结果，不由LLM自行判定动作生效。

## 人类旁观视角

对局中为无座位的平民式公共视角：看到日夜、阶段、座位、已公开存活状态、发言、公开票型和规则已经公开的结果。旁观者不拥有角色身份和私人操作信息，因此不是复制任意AI的完整上下文。

隐藏身份、狼队交流、刀人目标、查验、救人/毒人等尚未公开的信息，在对局结束前不发送到浏览器。AI主动发言声称的身份/操作作为发言展示，不认证其真实性。

正常结束后，揭晓全部角色身份，并按日夜展示实际投票、刀人、查验、救人、毒人及其他技能记录，供人类对照发言复盘。异常暂停不视为结束，不提前揭密。

## 竖版只读房间UI

依据用户提供的网易狼人杀竖版截图组织空间，采用自制图形和文字。截图只作为布局参考，其中场次人数、房间号、头像、文案和操作控件不是本游戏配置。

- 顶部固定房间信息、日夜标识与第几轮；日夜通过整体色调区分。
- 左侧从上到下为1–6号，右侧为7–12号；圆形头像配座位号、AI名字和公开状态。当前发言座位高亮，出局席位置灰但保留位置。
- 中间保留主要阅读空间，用于当前公开发言的座位号和文字，替代截图的大型人物立绘与语音展示；背景保持低干扰。
- 下方为可滚动的公开发言历史、票型与结果记录；终局后在原页面增加身份与隐藏行动复盘。
- 手机以竖屏布局为主；桌面将同一竖版房间居中呈现。屏幕高度不足时允许页面滚动，保证12席和文字可读。
- 不展示语音麦克风、礼物、红包、邀请、设置、输入框或游戏操作按钮，也不显示虚构的真人发言倒计时。

示意（仅布局，不代表实际身份或游戏状态）：

```text
┌─────────────────────────────┐
│ 房间 · 第N天/夜 · 公开阶段    │
│ ①                       ⑦   │
│ ②     当前发言座位       ⑧   │
│ ③     公开发言文字       ⑨   │
│ ④     日夜背景           ⑩   │
│ ⑤                       ⑪   │
│ ⑥                       ⑫   │
├─────────────────────────────┤
│ 公开发言历史 / 票型 / 结果    │
│ 结束后追加身份和隐藏行动复盘  │
└─────────────────────────────┘
```

头像和装饰不得暗示隐藏身份。对局中公开阶段仅展示如“夜间行动”的公共进度，不展示正在调用哪个神职、其座位或私有动作结果；只有公开发言阶段才高亮对应座位。
