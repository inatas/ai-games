# 全AI狼人杀 MVP 设计与规则 v1（规则已确认，实施参数待确认）

归属：[本地需求001](../.agents/note/001-ai-spectator-mvp.md)。依赖[房间制回合框架](../../../docs/specs/turn-based-matches.md)（通用框架v1已实现并有测试证据）。规则来源为用户指定的[LAL预女猎白页面](https://werewolves.games/yu-nv-lie-bai/)（2026-09-20读取）；2026-09-21用户逐条裁定下述规则细节，UI仅参考网易布局，不混用网易规则。

状态说明：**规则本身已由用户确认**（下文“已确认规则”）。仍待确认的只有3项实施参数与流程顺序，集中在[待确认项](#待确认项)，未定项不写入实现。实现、可执行测试、HTTP路由与UI尚未开始。

## 目标

狼人杀作为第三层MOD接入独立房间制回合游戏框架，与MUD共用最底层能力，不接入MUD地图、任务或NPC运行流程。创建一个12人AI狼人杀房间。每个角色独立绑定LLM，自主发言和决策。人类只旁观，不参与任何游戏操作。

## 阵容与开局

- 4狼人、4平民，预言家、女巫、猎人、白痴各1。
- 框架支持定义N个座位，狼人杀MVP固定12人。
- 服务端配置AI角色及模型，所有座位就绪后自动开始；12席可绑定同一提供商适配器，但每席独立scope与上下文，不共享私有历史。
- 仅做单个全AI房间，不做真人入座、匹配大厅或语音。

## 对局流程

座位就绪→分配身份→首夜→反复（白天公开结算→警长竞选（仅第一天，待确认）→依次发言→放逐投票→结算→黑夜）→满足胜负条件。

阶段图细节见[阶段与行动](#阶段与行动)。发言顺序与轮次预算见[待确认项](#待确认项)。

## 已确认规则

以下每条均为用户2026-09-21明确裁定，实现须逐条对应测试用例（见[验收](mvp-testing.md)）。

### 放逐投票与平票

- 放逐投票最高票若≥2人同票，进入PK：仅平票者再发言一轮，其他存活玩家投票时只能投PK台上的目标。
- PK重投仍平，本轮无人出局，直接进入黑夜。
- 允许弃票。报票时“弃票”与“零票”分开；票型展示区分三类：出X票、弃票、未举牌。
- 投票资格：仅存活玩家参与放逐投票（用户2026-09-21确认）。白痴翻牌后失去投票权且不能被投。
- 放逐投票结果公开到座位级明细票型（谁投了谁），旁观者与AI均可看到（用户2026-09-21确认）。
- 白痴被投票放逐时翻牌免死；翻牌后可继续发言，但失去投票权，且不再被其他玩家列入放逐投票对象（即不能被投票）。

### 狼人夜间行动

- 狼队少数服从多数：每名活狼各提交一个目标，按多数决定刀口；平刀时从平刀候选中随机抽取。
- 允许自刀；允许空刀，空刀为平安夜（法官报平安夜）。
- 夜晚不能自爆（预女猎白无血月/白狼王等特殊角色）。

### 发言顺序

用户2026-09-21确认：

- 白天发言从“前一夜死者的下一位”开始；方向由警长决定顺时针或逆时针。
- 平安夜无死者时，随机选择一名存活座位作为起点。
- 无警长时固定逆时针。
- 顺时针／逆时针按座位号循环理解（逆时针为座位号递减方向，12→11→…→1→12）。该解释随实现写入测试；如需改向请指出。

### 自爆时机

用户2026-09-21确认：白天的任意发言阶段均可自爆。自爆立即终止当前发言与投票并进入黑夜。竞选阶段自爆是否算“任意发言阶段”见[待确认项](#待确认项)第9条。

### 女巫

- 解药、毒药全局各一瓶。
- 同夜最多用一瓶，不能同夜双开。
- 全程不可自救（标准预女猎白）。
- 解药未用时，夜间告知“今夜倒牌的是X”，女巫决定是否救；救则知道被救者即刀口X。一旦用掉解药，之后不再提供刀口信息。

### 预言家

- 查验只返回“好人／狼人”，不返回具体神民身份。
- 不得连续查验同一人（沿用规则页）。
- 预女猎白无第三方：金水即好人，查杀即狼人。

### 猎人

- 可开枪：被狼刀出局、被白天放逐出局（含PK出局）。
- 不可开枪：被女巫毒死，或被非投票类技能带走（预女猎白仅涉及毒死）。

### 遗言

- 夜间死亡：仅首夜死亡有遗言；第2夜及之后的夜间死亡（狼刀／女巫毒）无遗言。
- 白天死亡：被放逐／投票出局有遗言。
- 猎人开枪带走的目标，按各自死亡时段补遗言（猎人夜晚被刀死则开枪目标有遗言；白天被放逐则开枪目标有遗言；猎人被毒不能开枪故无此情形）。
- 自爆狼一般无遗言；不实现自爆专属30秒遗言流程。
- 白痴翻牌免死不属死亡，不给遗言，只继续发言。
- 无警长局保留上述“首夜有遗言”，其余按本条执行。
- 猎人白天被放逐时的固定顺序：先说遗言→再开枪→开枪目标说遗言→进入黑夜（用户2026-09-21确认）。

### 警长与双爆吞警徽

- 上警：第一天白天先进行警长竞选；想当警长的依次发言，未上警者投票。
- 退水：上警者可在自己发言结束后、投票前退水；退水者不参与后续警长票，其已得票作废并重计（按房规）。
- 票权：警长1.5票，仅适用于放逐投票；警长竞选阶段尚无警长，不适用（用户2026-09-21确认）。预女猎白默认1.5，不改为1票或2票。
- 警长选举平票：平票者再发言并重投；再次平票则警徽流失，无警长继续，不无限重选。
- 竞选票型：只公开当选结果（当选者或警徽流失），不公开谁投了谁（用户2026-09-21确认）。
- 警徽流：预言家上警报“几验几、警徽给谁”即可，框架不强制格式，不解析该文本。
- 移交警徽：警长非自爆出局时可指定一名活人接警徽；警长自爆则按吞徽处理。
- 双爆吞警徽：警长竞选／上警阶段内，两名狼先后自爆（不要求连续两轮，但都发生在产生警长之前的竞选流程中）→取消警长选举，警徽流失，直接进入黑夜。
- 已选出警长后某狼自爆：只终止白天进夜，不吞徽。
- 单爆不吞徽，只终止流程进夜；不得实现为“一爆就无警长”。

### 胜负条件

- 好人阵营消灭全部狼人获胜。
- 狼人阵营按屠边结算：全部平民出局，或全部神职出局，狼人获胜。白痴翻牌后仍计为存活神职，神职全灭判定包含翻牌白痴（用户2026-09-21确认）。

## AI信息边界

每个AI只能看到当前规则允许的信息：公开场上状态、已公开发言与票型、自身身份和操作记录，以及角色允许的私有结果。狼人额外知道队友，并按规则获得狼队信息。

- 狼人：队友身份与夜间刀口提交记录（狼队内部可见）。
- 女巫：刀口信息仅解药未用时提供；自身药品余量。
- 预言家：自身历次查验结果与目标。
- 猎人：自身状态（是否可开枪）。
- 平民：仅公共信息。

AI上下文互相隔离；每个座位可绑定相同或不同LLM，但不能共享私有历史。AI负责选择行动和生成发言，服务器负责规则与结果，不由LLM自行判定动作生效。

## 人类旁观视角

对局中为无座位的平民式公共视角：看到日夜、阶段、座位、已公开存活状态、发言、公开票型和规则已经公开的结果。旁观者不拥有角色身份和私人操作信息，因此不是复制任意AI的完整上下文。

隐藏身份、狼队交流、刀人目标、查验、救人/毒人等尚未公开的信息，在对局结束前不发送到浏览器。AI主动发言声称的身份/操作作为发言展示，不认证其真实性。

正常结束后，揭晓全部角色身份，并按日夜展示实际投票、刀人、查验、救人、毒人及其他技能记录，供人类对照发言复盘。异常暂停不视为结束，不提前揭密。

## 竖版只读房间UI

依据用户提供的网易狼人杀竖版截图组织空间，采用自制图形和文字。截图只作为布局参考，其中场次人数、房间号、头像、文案和操作控件不是本游戏配置。

- 顶部固定房间信息、日夜标识与第几轮；日夜通过整体色调区分。
- 左侧从上到下为1–6号，右侧为7–12号；圆形头像配座位号、AI名字和公开状态。当前发言座位高亮，出局席位置灰但保留位置。
- 中间保留主要阅读空间，用于当前公开发言的座位号和文字，替代截图的大型人物立绘与语音展示；背景保持低干扰。
- 下方为可滚动的公开发言历史、票型与结果记录；终局后在原页面增加身份与隐藏行动复盘。
- 手机以竖屏布局为主；桌面将同一竖版房间居中呈现。屏幕高度不足时允许页面滚动，保证12席和文字可读。
- 不展示语音麦克风、礼物、红包、邀请、设置、输入框或游戏操作按钮，也不显示虚构的真人发言倒计时。

示意（仅布局，不代表实际身份或游戏状态）：

```text
┌─────────────────────────────┐
│ 房间 · 第N天/夜 · 公开阶段    │
│ ①                       ⑦   │
│ ②     当前发言座位       ⑧   │
│ ③     公开发言文字       ⑨   │
│ ④     日夜背景           ⑩   │
│ ⑤                       ⑪   │
│ ⑥                       ⑫   │
├─────────────────────────────┤
│ 公开发言历史 / 票型 / 结果    │
│ 结束后追加身份和隐藏行动复盘  │
└─────────────────────────────┘
```

头像和装饰不得暗示隐藏身份。对局中公开阶段仅展示如“夜间行动”的公共进度，不展示正在调用哪个神职、其座位或私有动作结果；只有公开发言阶段才高亮对应座位。

## 阶段与行动

阶段由框架的Phase承载（sequential/sealed、actors、决策JSON Schema）。以下为规划，阶段键名在实现时定稿；顺序中受[待确认项](#待确认项)影响的条目已标注。

是否启用警长（第一天竞选出警长）由房规决定；无警长时跳过警长竞选与发言方向阶段，发言固定逆时针。

| 阶段 | 执行者 | 收集模式 | 决策内容 |
|---|---|---|---|
| 身份分配 | 系统 | — | 随机且可复现的座位→身份映射（不使用LLM） |
| 夜间狼刀 | 活狼 | sealed | 各选一名目标或空刀 |
| 夜间女巫 | 女巫 | sealed | 用解药／用毒药／不用（互斥） |
| 夜间预言家 | 预言家 | sealed | 查验一名非连续目标 |
| 夜间结算 | 系统 | — | 计算死亡、药品消耗、可开枪状态 |
| 天亮公开 | 系统 | — | 公布死亡/平安夜，进入遗言流程 |
| 遗言 | 符合条件者 | sequential | 公开发言 |
| 警长竞选 | 上警者＋投票者 | sequential＋sealed | 仅第一天（有警长房规）；含退水、平票重投、双爆吞徽 |
| 发言方向 | 警长 | 行动或发言字段 | 每轮选顺时针／逆时针，决定发言起点与方向（待确认项3） |
| 白天依次发言 | 存活者 | sequential | 公开发言；起点为前夜死者下一位，平安夜随机起点；无警长固定逆时针 |
| 狼人自爆 | 活狼 | 行动 | 白天任意发言阶段可发起，立即终止当前发言与投票 |
| 放逐投票 | 存活者 | sealed | 投一名可投目标或弃票；警长1.5票 |
| PK重投 | 平票者发言＋其余存活者投票 | sequential＋sealed | 仅平票时触发；只能投PK台上目标 |
| 票型公开与结算 | 系统 | — | 座位级明细报票（出票／弃票／未举牌分开）、放逐或无人出局 |
| 猎人开枪 | 猎人 | sealed | 可选开枪目标或不开枪 |
| 遗言（猎人带走） | 被带走者 | sequential | 按死亡时段判定 |
| 胜负判定 | 系统 | — | 屠边条件 |

夜间顺序沿用规则页摘要：狼队行动→女巫→预言家→白痴确认→猎人状态告知→天亮。

## 待确认项

2026-09-21用户已确认发言顺序、投票资格、警长票权范围、放逐票型明细、竞选票型公开性、白痴存活计数、猎人开枪与遗言顺序、自爆时机。剩余未定项如下，确认前不写入实现：

1. **发言字数上限**：用户选择“我指定字数”，但尚未给出数值。请提供一个上限（例如每席每轮约XX字或XX句），用于发言Schema与模型输入预算。
2. **竞选阶段自爆是否算“白天任意发言阶段”**：用户答“白天的任意发言阶段均可”自爆，同时既有规则为“竞选阶段双爆吞警徽”。请明确二者关系，三种可能：
   - a) 竞选发言阶段也可自爆，且竞选期内两次自爆构成双爆吞警徽（与现有双爆描述一致）；
   - b) 竞选发言阶段不可自爆，双爆指第一天上警结束后、放逐投票前的两次自爆；
   - c) 其他房规。
3. **警长选择发言方向的AI动作**：警长每轮需在顺时针／逆时针间选择一次，该选择作为独立阶段动作（新增一次模型调用），还是复用其发言输出中的字段？两种都可行，倾向复用字段以减少调用。请指出偏好或交由实现决定。
