# 狼人杀 Robot 策略规则 v1（待确认）

通用执行协议见[框架设计](../../../docs/specs/decision-rules-engine-v1.md)；本文件只定义狼人杀 MOD 的规则实例及接入。

## WW-R01：预言家首日上警

| 项 | 拟议行为 |
|---|---|
| 触发 | 本人真实身份为预言家、首日 `nominations` 决策、本人按当前游戏规则可报名、合法选项含上警 |
| 概率 | 0.8，按本局稳定 occurrence 判定一次；数值待确认 |
| 命中效果 | `require-option` 指向本次合法的上警选项；模型/脚本只可提交该选项 |
| 未命中 | 上警和不上警继续由 Robot 自行选择 |
| 冲突与失效 | 与其他强制规则冲突则按框架错误处理；阶段被自爆抢占或报名资格变化后旧选择无效 |
| 审计 | 保存规则版本、判定、模型原提案及最终提交；对手和公共旁观不可见触发原因 |

不在系统提示词里用“必须上警”充当唯一约束。MOD 在生成合法动作后解析具体上警 option ID；框架执行概率、约束与提交复核。首夜死亡尚未公布时按既有竞选规则仍可上警；资格由游戏规则给出，策略层不自行修改。

## 待后续定义：女巫平安夜公开刀口

这需要 SPEAK 的结构化公开声明，而不是自由文本关键词检查。先确定至少四种局面：狼队空刀、女巫救人、毒杀与狼刀相抵后的无死亡、女巫已用解药且不再获知刀口。只在本人实际获知刀口并有合法公开发言机会时才可能建立声明义务。声明作为发言内容，不修改真实身份或夜间事实；何时必须跳出、是否可以因局势例外、是否由服务端渲染完整句子，均待规则裁定。本版不实施。
