# 狼人杀 Robot 策略规则 v1（已确认实施）

## 配置文件与注册

`mods/werewolf/src/decision-rules/seer-first-day.ts` 定义 WW-R01；同目录 `index.ts` 汇总规则集并导出 `id='werewolf.robot-strategy'`、`version=1`。`mods/werewolf/src/definition.ts` 注册该规则集。该规则适用于 Robot 席位，概率固定为 `0.8`，优先级 `100`，模式为 `require-option`。当前不提供房间配置覆盖或运行中编辑；未来修改概率须提升规则集版本。框架代码和中性测试不写“预言家”等游戏词。

通用执行协议见[框架设计](../../../docs/specs/decision-rules-engine-v1.md)；本文件只定义狼人杀 MOD 的规则实例及接入。

## WW-R01：预言家首日上警

| 项 | 拟议行为 |
|---|---|
| 触发 | 本人真实身份为预言家、首日 `nominations` 决策、本人按当前游戏规则可报名、合法选项含上警 |
| 概率 | 固定 0.8，按房间、座位、阶段实例及规则版本稳定判定 |
| 命中效果 | `require-option` 指向本次合法的上警选项；框架直接提交，不调用模型/脚本 |
| 未命中 | 上警和不上警继续由 Robot 自行选择 |
| 冲突与失效 | 与其他强制规则冲突则按框架错误处理；阶段被自爆抢占或报名资格变化后旧选择无效 |
| 审计 | 保存规则版本、判定及是否强制提交；此次无模型原提案；对手和公共旁观不可见触发原因 |

不在系统提示词里用“必须上警”充当唯一约束。MOD 在生成合法动作后解析具体上警 option ID；框架执行概率、约束与提交复核。首夜死亡尚未公布时按既有竞选规则仍可上警；资格由游戏规则给出，策略层不自行修改。
