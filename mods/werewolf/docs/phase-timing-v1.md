# 阶段时间与行动截止

状态：下表为当前狼人杀 MOD 定义的时间值；默认结算见[行动截止](action-deadlines-v1.md)，变更记录见[共用退水窗口需求006](../.agents/note/006-shared-sheriff-withdrawal.md)。后文旧版本建议仅保留决策来源，不覆盖当前定义。

## 计时表

| 步骤 | 当前上限 | 计时单位 | 截止仍无合法动作时 |
|---|---:|---|---|
| 狼人刀人 | 共享60秒 | 与预言家同一窗口 | 未提交狼人按空刀；已提交的合法选择保留，按原规则结算 |

| 警长PK发言 | 90秒 | 每名PK候选人 | 跳过发言，保留候选资格 |

| 放逐投票 | 30秒 | 所有有投票权者共用窗口 | 未提交者弃票 |

| 猎人开枪 | 30秒 | 每次合法开枪机会 | 不开枪 |

| Robot 有效白天发言展示 | 持续至原阶段截止 | 普通发言、上警发言、PK发言 | 不再提交后3秒换人；视觉显示完成不结束阶段 |
| 狼人自爆 | 无独立倒计时 | 仅允许自爆的阶段内随时插队 | 未主动提交即不自爆，不为等待自爆阻塞普通流程 |

不增加守卫等不属于当前预女猎白板子的行动。死亡、开枪、遗言和警徽顺序沿用既有队列，不因表格顺序改变。无遗言权、毒死不能开枪、1人上警自动当选等直接按原规则处理；所有出局连锁结算完后才判胜负。

## 当前计时口径

1. 各阶段以服务端固定窗口计时；退水固定到10秒边界统一结算，不因全员提前提交而提前结束。2026-09-26用户取消Robot发言提交后3秒换人；合法发言提交后仍持续到原阶段截止，视觉显露和关闭气泡不改变窗口。
2. 计时从阶段窗口正式开始算起，模型生成、校验和至多一次格式纠正均共享原截止点。重试、刷新与恢复不重设窗口。多人阶段席位并发收到各自任务。
3. 夜间狼人刀人与预言家查验共享前60秒；刀口锁定后女巫有后续30秒。女巫已出局也保留完整90秒黑夜，公开页面不显示行动席位或私密完成状态。
4. 服务器判定截止时间，前端仅展示。恰好到期与迟到输出不能覆盖默认动作；自爆抢占成功后，原阶段未结算结果失效。模型失败不直接判负或揭露身份；数据库/规则异常停止推进，不能伪装成默认成功。
5. 正式对局打开历史或其他面板仍继续计时；重启沿持久截止点恢复。游戏发言只有完整合法提交才成为公开的玩家正文，超时不得伪造分析。

## 尚未纳入当前规则的历史提案

早期曾提出预言家跳过查验、独立的暂停/倍率及更长发言等方案；当前预言家到期按合法目标确定性随机查验，发言上限由 MOD 规则配置为200字，页面不暂停正式对局。具体实现以本页当前计时表、行动截止文档和代码定义为准。

通用计时/恢复能力归第二层中性文档，狼人杀阶段映射和默认动作归本 MOD。以下 v1.1～v1.3 为历史裁定过程，不作为当前时限。

## v1.1参考依据与修订（历史，夜间以v1.3为准）

用户要求参考网易狼人杀、时间略微加长。2026-09-21查阅[网易狼人杀产品介绍](https://www.taptap.cn/app/55012/all-info?platform=android)，其中明确宣传120秒发言；[官方微博](https://www.weibo.com/6285336793/PhNcd9UeG)简介也有同样描述。未找到该产品当前预女猎白全部阶段的官方时限表，不能将本建议其他数字称为网易原值。

当时曾建议150秒普通/上警发言、共享75秒夜间与20秒逐人退水；这些数字已由后续确认取代。

当时关于提前推进、查验和历史浮层的未决项已由后续固定窗口、默认动作与 v4 页面方案取代。

## v1.2用户裁定（已被v1.3替代）

用户明确指出“这3个时间，应该是共享75秒，每个角色各做各的操作”。因此夜间总窗口为75秒，非三个角色独立时限相加。先前助手提出165秒/225秒为错误理解，不再采用。

当前实现的wolves→witch→seer是内部顺序状态机，后续开发须调整为共享窗口收集，不能以现有代码顺序反推玩法。女巫救药依赖刀口的信息发布/刀口锁定时机仍需在共享窗口方案中明确，不擅自改成盲救，也不另加75秒；本次只确认时间规则，不实现并行状态机。

## v1.3最新裁定

用户明确要求：狼人刀人与预言家查验共享60秒；女巫用药在狼人行动结束后30秒。该裁定替代共享75秒的旧方案，夜间为60+30结构，合计上限90秒。观看控制直接复用现有单步、1×、2×、4×，不新增速度选择界面。

## v3/v4演示沿革（历史）

当时用户授权标准速度、暂不做1×/2×/4×，固定一句话发言；[watchable-demo-v3.md](watchable-demo-v3.md)实现了狼人＋预言家共享60秒后女巫30秒。旧wolves→witch→seer描述不再代表当前代码；超时默认动作后来已在[行动截止](action-deadlines-v1.md)确认。

v4替代局中暂停：正常对局由服务宿主持续推进，查看历史或其他面板都不停表；无暂停、单步或倍率接口。夜间60＋30秒不变；2026-09-26取消固定短句3秒换人，发言遵守原阶段截止。
