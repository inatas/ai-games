# 静默旁观UI实施契约

对应[需求001：UI实施v1](../.agents/note/001-ai-spectator-mvp.md)，用户于2026-09-21确认原型并授权实施。视觉基准为[已确认原型](prototypes/ui-v1-day.png)。

## 页面与美术层

`/werewolf`为独立React入口，按1:2舞台比例呈现。宽屏居中，手机按屏宽显示；短屏可滚动。`apps/web/src/mud.tsx`保留原MUD入口和样式，按路径分别加载，避免主题污染。

- `apps/web/public/werewolf/room-background.png`：依据已确认原型经图像生成工具拆出的木框、顶部装饰与旧村庄底图。
- `apps/web/public/werewolf/portrait-atlas.png`：已确认原型的副本，用CSS裁切头像、骷髅、导航装饰和下方人物区域；不将整张截图覆盖成假界面。头像裁切排除预览序号与身份牌，角色形象仅为装饰。原图中死亡席位的存活头像使用其他装饰头像。
- 文字、动态号码、警徽/白痴公开牌、昼夜标识、进度、战报、弹层、全部控制为真实DOM。切换席位展示该席位装饰肖像和公开资料；5号保留原型大立绘。
- 初始预览的3/8号出局、10号翻牌、5/9进度均标明是预览。开始演示后全部替换成服务端公开数据，预览票型不伪造成实际投票。

参考图由用户提供；原型及独立底图由图像工具生成。素材不是从第三方网站下载的游戏资产。

## 本地演示接口

独立服务入口 `apps/server/src/werewolf-demo.ts`，仅绑定127.0.0.1，默认4318端口，可用WEREWOLF_PORT修改。相同路由作为隔离插件装配到标准应用；其MUD入口、错误处理和Origin规则不受该插件影响。独立服务首页跳回狼人杀预览，标准应用首页保留MUD。内存会话最多100个，闲置1小时失效；无数据库迁移或网络模型调用。每局为12个静默策略角色，既有规则引擎决定合法动作、阶段和胜负。本版策略不主动自爆；已有抢占规则及其验收保持不变。

| 请求 | 入参 | 结果 |
|---|---|---|
| POST `/api/werewolf/demo` | `seed`为uint32整数；`strategy`为fixed/random | 创建独立随机UUID会话，返回初始公开快照 |
| GET `/api/werewolf/demo/:id` | UUID | 返回当前公开快照；不存在/已过期返回404 |
| POST `/api/werewolf/demo/:id/step` | `revision`为预期修订号 | 推进一个决策；同一最近修订重试返回同一结果，过旧/未来修订返回409 |

随机UUID是仅本机演示会话的临时访问凭据，未提供列表接口。带Origin的请求必须同源；不启用跨源访问。请求拒绝额外字段和类型强转。服务端在同步纯计算成功后同时提交游戏状态和策略随机状态；失败不推进。

公开DTO位于`apps/shared/werewolf.ts`，应用端只依赖该契约，不导入MOD规则。字段为会话id、修订、状态、日夜、阶段标题、公开行动者、公开放逐投票提交进度、席位公开生死/白痴牌、警长和已公开事件。夜间actor/progress恒为null；不返回规则state、Schema、私有阶段、scope或模型上下文。角色和完整已发生事件回放只在正常finished状态返回，异常停止不揭密。

## 控制与恢复

暂停、单步及速度只控制浏览器发起请求的节奏；每次仅允许一个在途请求。弹层打开期间停止自动推进，关闭后恢复原播放状态。速度不改变种子或行动结果。发言/遗言为空字符串，连续公开发言事件在记录中合并展示。

重开面板允许选择种子和策略，经“确认重开”才创建新局；取消不改变当前对局。临时通信失败可重试最近修订，409读取服务器当前快照以重新同步。过期会话提示重开。正常终局可查看12席身份、真实投票表及日夜分组记录。

终局投票详情显示各席目标、弃票/未举牌、加权票数和PK结果；进行中不会返回投向，警长个人票在终局前不开放。回放显示已发生事件，无预先生成的未来记录。

## 验收入口

`mods/werewolf/tests/demo.test.ts`验证固定/随机整局、静默发言、确定性、重复推进及夜间/终局信息边界；`demo-http.test.ts`验证实际Fastify路由、并发重复请求、未知会话、冲突、跨源与非法字段不改变状态。浏览器验收记录见需求001的本次实施证据。
