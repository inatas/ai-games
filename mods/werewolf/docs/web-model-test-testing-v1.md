# 狼人杀网页模型测试台 v1 验收说明（历史版本）

浏览器口令相关用例 WW-W06 已由[本机测试台 v1.1](web-model-test-testing-v1-1.md)取代。

关联[设计](web-model-test-v1.md)。用户已确认实施；相关自动化和本地网页检查已通过，真实供应商整局验收仍待用户操作。

| ID | 场景 | 通过标准 |
|---|---|---|
| WW-W01 | 网页配置 | 12 席可设置可用 profile，脚本席不可选择；草稿刷新保留；未点击开始不发模型调用 |
| WW-W02 | 服务端防伪与幂等 | 未知/不可用 profile、脚本席填模型 profile、同 requestId 改阵容或 profile 均拒绝；重复请求只建一个房间 |
| WW-W03 | 页面恢复 | 复制房间 ID 后换浏览器会话、刷新或重启服务，仍能加载同一持久房间、阶段与诊断日志 |
| WW-W04 | 流程与回放 | 局中只看已公开事件；终局可看现有身份和夜间完整历史；诊断事件不混进公开发言/投票时间线 |
| WW-W05 | 成功与失败 | 逐次调用展示实际结果、错误和重试；返回无效、裁判拒绝、请求未发出与 API 失败状态各不混淆 |
| WW-W06 | 浏览器权限 | 无/错误测试口令不能开局、读取 profile、完整诊断和席位私有视角；经 Docker 发布端口携正确口令可用；普通旁观和未结束历史无模型原始 context、对手私有事实或密钥 |
| WW-W07 | 缓存指标 | 列表、席位/阶段和整局统计与底层事件逐项一致；缺失用量标为未知，冷请求可辨 |
| WW-W08 | 实际整局 | 用户从网页开一局真实模型，持续看阶段，终局看回放；房间 ID 与调用数、错误码、token/cache 指标留在持久库供复查 |

先实现可失败自动化行为测试和接口验证，再做浏览器人工验收；WW-W08 必须用真实供应商而非 ScriptedModel，未跑不记通过。
