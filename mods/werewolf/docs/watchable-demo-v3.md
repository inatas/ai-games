# 无模型完整观战演示 v3

状态：历史版本，已由[观战v4](spectator-flow-v4.md)替代；下述暂停/单步/GET驱动语义不再适用于当前代码。v3曾确认并实现。所属需求001。本页替代此前待审方案中的倍率、模板分析、commandId与模型兜底设计；浏览器验收证据记录在需求note。

## 范围与节奏

- 使用现有UI观看固定/随机策略真实对局，不接模型、RTC或数据库。服务重启后需重开，未提供持久恢复。
- 狼人刀人与预言家查验在同一密封阶段收集，共享60秒；刀口锁定后女巫另有30秒。查验仅本人可见，刀口按原规则给女巫。没有独立预言家计时阶段。
- 标准速度播放、暂停、单步、重开；移除1×/2×/4×。服务端可注入时钟，页面每250毫秒读取公开快照，不用浏览器定时点击step模拟时限。
- 夜间公开倒计时统一90秒，前60秒与后30秒分别推进。女巫已死仍保留后30秒等待；公共修订号每个可观看步骤只增加1，不暴露私密行动人数。
- 公开行动采用固定/随机合法选择，每步保留3秒后提前完成。普通及上警发言预算150秒，PK与遗言90秒，上警/投票/开枪30秒，方向/退水/警徽移交20秒。这些是本地演示预算；不将尚未确认的模型超时默认动作作为玩法实现。
- 单步自动暂停并结束当前等待：夜间推进前段或后段，密封报名/投票整批提交，其他阶段推进一名发言者或一个连锁动作。所有出局链走完再判胜负。
- 打开历史等弹层暂停时钟，关闭恢复原播放状态。后台页面恢复读取时逐步显示，不一次跳过多个公开阶段。

## 发言与公开边界

DemoRooms的speechText配置默认“我是狼人杀玩家”，非空且最多配置的200字符。上警、警长PK、放逐讨论、放逐PK和合法遗言均经规则提交这句文字；不模拟分析，也不声称为模型输出。本版固定/随机策略不主动自爆。

真实历史按事件sequence、day、phase、seat、text投影，按天筛选、保留发生顺序和阶段。主面板仅显示发言完成提示，不显示正文。初始预览仍有明确标识的长文示例，真实对局不混入示例。角色及私密夜间事件仍只在正常终局揭示。

## 接口与实现

- POST /api/werewolf/demo：seed、strategy创建本地内存会话。
- GET /api/werewolf/demo/:id：读取并按当前时钟最多推进一个可观看步骤。
- POST /api/werewolf/demo/:id/step：revision，暂停并单步。
- POST /api/werewolf/demo/:id/control：revision、playing，控制单速播放。

DemoSnapshot新增playing、timing.remainingMs和speeches数组。夜间不返回行动者、角色存活状态、私密阶段标识或完成数。最近相同修订的step/control重试不重复执行；过时冲突返回409，前端读取同步。请求拒绝额外字段及类型强转；倍率参数不支持。

共享夜间规则及角色动作校验归MOD，定义版本升至4；DemoRooms负责时钟和演示策略，应用层仅消费公开DTO。不修改第二层通用计时、数据库或模型协议。旧版内存会话/API不兼容，依项目未发布升级规则直接更新调用方。

WD-01～07覆盖共享窗口、角色动作边界、60＋30秒、暂停、重试、自动与单步整局一致、固定短句、历史顺序、自定义句子及HTTP参数。既有规则测试继续验证死亡链、竞选、猎人、警徽、平票和终局信息边界。时钟测试注入时间，不以模拟时钟声称真实等待验收。
