# 狼人杀 Agent Notes

本目录继承[项目开发规则](../../../../AGENTS.md)和[通用 Note 生命周期](../../../../.agents/note/AGENTS.md)。狼人杀专属的新独立 feature 使用本目录下一个三位序号；同一 feature 续写原 note，并同步[本地索引](README.md)。

`Status:` 仅用 `proposed`、`implemented`、`rejected`、`archived`，含义与迁移条件以通用 Note 生命周期为准。玩法、计时、默认动作及验收更新 `mods/werewolf/docs` 中相应的现有主题文档，不能为每个 feature 默认新建平行 docs。公共房间或模型机制另建根 note 并互链。方案待确认、实施中或范围内验收未完成时保持 `proposed`；状态与用户审阅记录分别记载。
