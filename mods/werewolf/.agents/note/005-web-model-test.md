## 需求

用户希望通过网页配置并启动真实模型对局，查看阶段流程与终局回放；每次成功或失败的模型 API 调用要能查日志，并观察当前不足 20% 的 KV 缓存命中情况。现有网页可配置十二座 Robot、种子并开局，能看旁观流程和终局历史；模型 profile 由 Robot 文件固定，网页无模型调用诊断；上次临时测试库清理后日志不可再查。接入设计见[网页测试台 v1](../../docs/web-model-test-v1.md)，底层日志和缓存分别见[框架 021](../../../../.agents/note/021-event-log.md)、[框架 023](../../../../.agents/note/023-model-context-cache.md)。

## 范围

本次拟实施：现有座位管理选择已配置的可用模型 profile 并冻结到新房间、显式开局；进行中看阶段和公开事件；终局复用现有对局历史和身份揭晓；新增测试口令保护的模型诊断面板，能筛选座位、阶段、成功/失败/未发出，查看请求、响应、错误码、延迟和实际 token/cache 数据；刷新与服务重启后可按房间 ID 继续查看。网页不编辑模型密钥/URL，不改规则、阶段计时、模型服务启动方式，不把私有请求放进公共历史。

## 接口、数据与状态

只展示服务端登记的 profile ID/显示名/可用状态；开局请求增加每座 `profileId`（脚本席为空），校验其与座位、Robot 类型、服务端配置匹配，房间持久化 profile 绑定并沿用开局幂等键；同 key 不同阵容或 profile 返回冲突。测试房间使用现有持久模型房间，普通时钟自动推进；开局后页面收藏房间 ID 并可手工输入 ID 恢复，避免仅靠浏览器 sessionStorage。阶段流程和回放仍来自游戏房间快照，诊断日志来自 `fw_event_log`，两者不是同一种事件。测试过程不删除房间或日志，用户以后显式清理。

网页展示“供应商已返回”“供应商调用失败”“已返回但裁判未接受”“尚未发出”“结果未知”五种状态，不将模型返回等同有效行动。私密日志和原始 context 只在本机诊断 API 与页面出现，普通旁观和终局公共回放继续按既有权限。确认后先写行为/边界测试，再接服务端配置和诊断投影、网页，最后真实对局验证。详细边界验收见[测试说明](../../docs/web-model-test-testing-v1.md)。

## v1.1 已确认：本机测试免手工口令（2026-09-25）

确认记录：用户审阅 v1.1 后明确要求“明确测试平台为本地，不需要额外增加密码保护。实施代码”。确认范围包括移除浏览器测试口令、将本机模型凭据放在用户目录专用文件并由后端读取、仅本机发布端口以及相应接口和页面调整。

用户指出座位管理不应每次要求输入“测试口令”，希望模型 API Key 长期放在 `~/.codex` 并由项目读取。当前 v1 的 `MODEL_TEST_TOKEN` 保护付费开局、私有席位视角和原始模型调用日志；模型供应商 Key 已只在服务端环境中使用，两种口令职责不同。本变更仅调整本机狼人杀测试台，不修改现有已实施 v1 的历史记录。具体接口与启动方案见[网页测试台 v1.1](../../docs/web-model-test-v1-1.md)，验收见[测试说明](../../docs/web-model-test-testing-v1-1.md)。

拟实施范围：移除座位管理与诊断面板中的测试口令输入和“连接模型服务”步骤；本机测试模式下页面直接读取可用 profile、开局、切换私有视角及查看诊断。仅在显式本机测试模式下开放这些接口，Docker 发布端口绑定 `127.0.0.1`；未开启本机模式时不开放付费开局和私有诊断。模型供应商 Key 放入用户目录下专用 `~/.codex/ai-games-model.env`，由本项目启动脚本读取并注入后端进程或容器环境；Robot/Profile 文件只存变量名。不得把 Key 写进 TypeScript 常量、网页、仓库 `.env`、日志或模型上下文。其他环境的正式身份授权留待独立方案。

接口、状态和数据：房间与日志表不变，`profileIds` 及幂等开局不变；本机模式访问模型接口不再要求 `x-model-test-token`，`MODEL_TEST_TOKEN` 停用。启动脚本须校验专用文件存在、所需变量齐全和端口绑定条件，失败时不启动付费模型服务。启动后单个后端进程向多个 profile 对应的外部 HTTP API 发请求，不为每个模型另起服务。

验收：本机网页刷新和重启后无需再输测试口令，可选 profile、开局、查看私有诊断；API Key 不出现在页面响应、打包资源、日志与仓库文件；非本机模式无法调用付费开局和私有诊断；端口仅监听宿主回环地址；缺凭据或启动配置时明确失败。先写接口与启动边界的失败测试，再实现并验证。当前状态：**已确认，待实施**。
