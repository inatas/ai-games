# 需求：狼人杀 Robot 策略规则集

Status: proposed；MOD 接入方案 v1 已确认实施（2026-09-23）。

确认记录：用户审阅本 note 与框架 022 后回复“ok，进入开发，确认规则文件的具体配置和目录。”首版实施 SELECT 预言家上警，固定概率 80%；女巫 SPEAK 规则不在本轮。跨模块改动前检查点 `main/8a61408`。具体目录与配置见设计文档。

## 需求

让全 AI Robot 对局中的角色策略可执行、可追溯。

## 范围

全 AI Robot 对局中，按可审计的 MOD 规则稳定执行角色策略。框架执行机制见[根需求 022](../../../../.agents/note/022-decision-rules-engine.md)，本 MOD 只定义触发局面、合法目标、例外与观测指标。用户已确认框架负责运行机制、MOD 负责具体规则的架构方向；没有确认本版行为数值与接口实施。

首个规则为“预言家首日有报名资格时，以 80% 概率要求上警”。80% 作为首版固定数值。概率未命中时仍允许模型自主上警。规则不得把已经失去资格的人重新设为候选；首夜死亡但死讯尚未公布者仍按现有竞选资格处理。对应 SELECT 输入由现有 MOD 决策适配构造，规则只引用当次合法的上警选项。命中时框架直接提交合法上警选项，不调用模型。

“平安夜真女巫报刀口”记录为后续 SPEAK 规则候选，**不进入 v1 实施**。现有游戏仅在解药未用且女巫行动阶段提供刀口信息；空刀也可能形成平安夜。是否公开、何时公开、如何结构化声明以及女巫没有刀口信息时的行为均需单独裁定。禁止从平安夜公共结果推测或编造刀口。

## 接口、状态及验收

MOD 在服务端注册预言家规则的纯触发/目标函数，输入为本人授权视角和本次合法选项；不向框架传全知 Match 作模型上下文，不向公开事件暴露身份判定原因。具体方案见[策略规则设计 v1](../../docs/decision-rules-v1.md)。规则集版本在房间开局固定，概率判定和执行记录由通用框架持久化，不能因重试、跨夜竞选或恢复重抽。

行为用例：首日合资格预言家命中后上警；未命中保留原选项；非预言家和后续日不触发；首夜未公布死亡仍可触发；自爆导致旧报名失效时旧结果不提交；模型/脚本同样受约束；不同随机种子统计命中率但不以单局证明 80%；日志不泄漏预言家身份。确认后先写可失败测试，再接入规则集，运行 MOD 单元、框架回归和真实数据库恢复检查。未确认前不修改代码或可执行测试。
