# 014 全职业战术知识与角色扮演指南

Status: proposed

## 需求

让当前板子的六种职业都具备与本人角色目标相符的战术知识。狼人能主动悍跳、自刀骗药、冲锋、倒钩和控票；好人职业也应能报信息、应对身份争议、分析票型并调整判断。2026-10-08 用户先要求按推荐顺序产出 note 和 docs，随后明确战术应补充在本人角色扮演 Markdown，且每个职业都应补齐，并要求“调整”。

归属狼人杀 MOD。本需求是新的战术行为，不重做 008 的知识加载机制，不把战术建议写入框架协议。后继为 [015 每席战术承诺](015-seat-strategy-continuity.md)、[016 狼队协商](016-wolf-team-deliberation.md)。

## 方案 v1.2：已确认，工程已实施

首个开发阶段扩充现有六种职业的本人角色扮演指南，并澄清真实信息与公开说辞的边界。设计与数据边界的唯一正文为[模型接入：全职业战术优化路线](../../docs/model-integration-v1.md#全职业战术优化路线)，验收为 [WW-WK](../../docs/mvp-testing.md#全职业战术知识与连续性验收)。

## 范围

- 人工编辑 `knowledge/guides/{wolf,seer,witch,hunter,idiot,villager}.md`。这是当前项目的 roleplaying 内容入口，沿用一职业一篇的既有文件，不新建平行 `roleplaying` 目录。
- 每篇均包含角色目标、适用条件、执行方式、风险和调整／退出条件，覆盖本人能力、发言、选择及信息边界；各职业主题与验收以 docs 正文为准。
- `knowledge/roles/<role>.md` 保存全员可见的能力、限制与共同约定。明确补充 `roles/seer.md` 的警徽流：提前声明验人顺序及逻辑，本次验好人则交给本次目标，验狼人则按约撕徽或交给更早验好的玩家，并说明适用条件与例外。`guides/<role>.md` 仅本人加载，保存如何选目标及执行战术的指导；不新增警长职业文件。
- 精化 MOD 固定提示：允许游戏内伪装和假查验，私有判断不能把自己的说辞认证为实际技能结果。
- 沿用四层知识与当前缓存顺序、知识摘要和定义版本核对；不热改运行中房间。

不包含：新增行动、额外模型调用、战术抽样器、强制悍跳／自刀、共享狼队计划、私有记忆新字段、JEV 切换或历史清理。已有 `wolf-vote-control` 聊天草案不因此变成运行规则；其场景匹配和票权投影留在 002 后续审阅。
