# 需求：每席个人证据判断记忆

Status: proposed

## 需求

用户要求所有模型 Robot 在本人的每次 SPEECH 或 SELECT 交互中，同时更新自己对本局证据的判断；只写本局本席的私有记忆。共享公开证据链[需求 008](008-public-evidence-and-terms.md)已经实现，所有席位同水位看到同一公开记录；本需求增加各席可以不同、会随新证据变化的个人解释，不把推断当裁判事实。通用记忆机制见[根需求 031](../../../../.agents/note/031-decision-private-memory-update.md)。

## 范围

方案 v1，**用户已确认，工程实现完成，真实模型局待验收**。保留现有六区输入、知识库和公共证据构造；本席上一份个人判断通过现有后部 `REQUIRED_MEMORY` 注入，不新建输入区，也不插到 KV 共享前缀。SPEECH 输出仍必须有合法 `speech`，SELECT 仍必须有合法 `selected`；二者新增可选的 `personal_evidence_update` JSON 字段。提示模型每次给出字段，但缺失、空值或字段内部格式错误时不拒绝合法行动，保留原记忆。整份输出无法解析或行动字段非法仍走原有严格校验。

附加字段是**有界增量**：`upserts` 最多 2 条，每条有稳定 `topicKey`、简短 `judgment`、一个或多个来源引用（公开事件序号或本席授权私有事件序号）；`removeKeys` 列出撤回的旧判断。MOD 独立检查结构、长度、重复 key、来源权限和来源确实处于本次冻结的可见水位；不能凭发言声称认证身份、查验或用药。合格增量按 key 合并到本席个人判断 fact，保存来源引用；新证据可修正或撤回旧结论，历史公开事件不改写。个人判断只是一份模型可变观点，不计入 `public_history`、裁判状态、其他席位记忆或公共日志。金水、银水保留来源可信度和狼自刀边界，不强制统一站边或数值评分。为容纳 200 字 SPEECH 加附加字段，狼人杀模型输出预留由 500 提至 800 token；实际额外用量依供应商返回记录，不额外发起模型调用。

相同决策请求只调用一次模型。没有新证据仍允许空增量；未提交的夜间行动、其他席私有结果及终局真相不能成为引用。被规则直接强制、脚本决定、默认结算或模型失败时不新增个人判断；下次模型交互再读授权的新证据。旧个人判断若与最新裁判事实冲突，在上下文里始终由当前事实优先，模型应更新或撤回，但程序不把旧判断冒充事实。个人判断输入预算必需且有长度上限；超过可用预算时沿用现有显式失败，不静默丢掉裁判事实。

字段、验证与模型消息顺序见[狼人杀模型接入](../../docs/model-integration-v1.md#每席个人判断-v1已实施真实模型待验收)，验收见[狼人杀测试](../../docs/mvp-testing.md#每席个人判断-v1工程已实施真实模型待验收)。

## 验收

- [ ] 同一公开水位，两个席位有相同公开证据，但可保存不同个人判断；私有查验或用药仅更新有权席位。
- [ ] SPEECH 和 SELECT 各至少一次合法行动携带合法增量，下一次本席请求在后部必需记忆看到更新；其他席、公共前缀、旁观和回放不出现该判断。
- [ ] 附加字段缺失、空值、错误类型、非法来源、超限或重复 key 均只忽略附加更新；合法 `speech`/`selected` 照常提交。整份 JSON 失败或行动字段非法保持原有严格失败。
- [ ] 新证据修正/撤回旧判断，公开原始证据保持；重试、恢复、重复请求、阶段失效或抢占不重复写入或泄漏。
- [ ] 对一局真实模型日志抽样：判断引用确实可见的来源，后续 SELECT/SPEECH 可接续个人判断；记录模型未按建议输出更新的比例和额外输出 token。此项不由模拟测试替代。
