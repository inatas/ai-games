# 狼人杀模型网络失败恢复

Status: proposed

## 需求与范围

000015 的 3、4、7 号上警发言模型请求约 8 秒后发生无 HTTP 响应的网络错误。拟在原阶段截止前使用[框架有界重试提案](../../../../.agents/note/030-bounded-model-network-retry.md)，使 SPEECH 和 SELECT 均有至多两次有间隔的网络重试机会；不改变[行动截止与默认结算](../../docs/action-deadlines-v1.md)或每席位已配置的模型。狼人杀的配置、异常显示和实局验收见[模型接入文档](../../docs/model-integration-v1.md)。

## v1.1 待确认范围

狼人杀模型服务显式启用框架重试策略：一次初始调用、至多两次网络重试，全部 HTTP 调用合计上限 3；每次重试在前次失败落日志并经过独立间隔后，才检查同一行动窗口及剩余时间并重新发起。连续故障触发按模型 profile 隔离的短时熔断，等待原截止点由裁判执行已确认的默认动作。公共界面不泄露私密席位的失败原因；私有诊断保留逐次 attempt 与最终结果。脚本席位和 JEV 旁路不受此提案影响。

## 验收

- [ ] 120 秒上警发言在第 8 秒网络失败时，时间充足则可依次补发最多两次；每次与前次失败保持配置间隔，成功则按原阶段规则提交，失败则等原截止点标记未发言。
- [ ] 30 秒 SELECT 仅在剩余时间足够时逐次重试，可能用不满两次机会；不重置倒计时，也不提前执行默认动作。
- [ ] 对局模型日志能关联每次调用、重试理由、实际 usage 和游戏是否采纳；无响应的 token 不记为 0 或推测账单。
