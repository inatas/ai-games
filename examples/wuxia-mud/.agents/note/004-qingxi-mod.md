# 需求：青溪镇MOD接入

Status: draft

## 需求

将当前武侠示例明确为青溪镇MOD，承载世界观、故事、地图、NPC、门派、技能、具体规则和表现配置。通用MUD能力提取到框架。

## 范围

产品方向已确认，详细v1待审阅。关联[框架012](../../../../.agents/note/012-ai-mud-framework.md)。实现时迁至mods/qingxi，保留001～003来源与验收记录。已有玩法保持，新增一个最小两人协作委托验证party任务归属。

协作委托提案：药师“护送药箱”，恰好两人队伍在药铺领取时冻结参与者；两位成员各自到林地执行一次“勘察药路”，无需AI；两人完成后任一成员在药铺提交，任务完成。每位符合资格的原成员在药铺分别领取一次经验5、潜能2；药箱是任务状态，不生成可交易物品。离队、解散、后来入队的资格遵循框架共享任务契约。此配置待共同确认，不提前编码。

## 验收

- [ ] QX-01：迁移后原房间、成长、战斗与社交路径可用，旧档不丢失。
- [ ] QX-02：只修改MOD可更换组织、技能标签、地图与世界观，通用包无武侠字段。
- [ ] QX-03：双人委托、非成员拒绝、重复勘察、并发提交/领奖、离队及解散正确。
- [ ] QX-04：青溪镇可作为可玩MOD与Quickstart，测试和需求均有唯一入口。

## 当前进展

仅完成接入需求文档。代码仍位于examples/wuxia-mud；002/003保持未完成数据库验收状态。接口、事务、测试契约由根设计统一维护；MOD只注册勘察、提交、领奖动作及其严格输入Schema，不自建共享任务协调机制。
