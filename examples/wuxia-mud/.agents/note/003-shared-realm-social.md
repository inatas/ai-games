# 需求：共享江湖与轻量社交

Status: in_progress

## 需求

将现有“每个用户一套独立世界”调整为同一realm中的共享空间，并保留每位玩家私有角色、物品、任务和记忆；提供同房发言、私聊、全服频道及临时队伍的最小社交能力。

## 已确认范围

用户于2026-09-16确认架构调整并要求执行002和003。v3采用一个固定共享realm；房间拓扑与公开在线投影共享，玩家状态仍以scope隔离。`say`仅投递当前房间，`tell`仅双方可见，`chat`对realm可见；`invite/accept/leave`建立最多4人的临时队伍。在线状态按最近活动时间窗口推导，不引入WebSocket，页面轮询刷新。

社交记录属于游戏数据；仅与当前NPC判定相关、经宿主筛选的摘要进入Harness上下文。聊天文本不成为系统指令。设计、隐私、锁序和接口见[成长与共享江湖v3](../../docs/v3-growth-social.md)，测试契约见[v3测试设计](../../docs/v3-testing.md)。

## 验收

- [ ] SR-01～03：两个账号看到共享房间中的玩家及正确在线投影。
- [ ] SR-04～06：say/tell/chat可见性、长度限制和持久化。
- [ ] SR-07～09：邀请、接受、离队、容量、幂等与并发。
- [ ] SR-10：新局只重建私有角色，不重置realm或其他玩家。
- [ ] SR-11：Harness上下文不泄漏私聊和无关玩家数据。

## 当前进展

调整前基线为`main / ed0a827`。共享realm为游戏层能力，不修改Harness公共协议；应用服务器只负责身份授权和HTTP装配。
