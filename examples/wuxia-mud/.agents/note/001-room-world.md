# 需求：房间驱动的武侠世界 MVP

Status: draft

## 需求

参考侠客行MUD以房间、人物、物品和行动组织世界的方式，将现有四动作Demo扩展为可探索、可交互、可持续保存的Web武侠示例。采用原创小区域和人物内容，不逐房间制作背景图。

## 范围

v2待用户确认，替代v1草案。包含职责边界、B/S呈现、12个房间、5名NPC、L2节点地图＋轻量L3三类场景模板、物品背包、一条任务、基础成长、有限AI判定和存档兼容设计。默认每用户独立世界实例；L1战略图、势力/天气、自主Agent、自动寻路、推送和地图编辑器均暂缓。

设计与接口、数据契约见[武侠世界MVP设计](../../docs/world-mvp.md)，验收与夹具说明见[测试设计](../../docs/world-mvp-testing.md)。公共上下文扩展关联[框架011](../../../../.agents/note/011-composable-game-context.md)，其v1仍待单独确认；本需求不改变公共协议。

地图投影、信息边界及交互见[地图表现设计](../../docs/map-presentation.md)，开发阶段和版本回退见[实施计划](../../docs/world-mvp-plan.md)。

## 验收

- [ ] WM-01～04：地图、移动、可见性和NPC在场约束。
- [ ] WM-05～08：背包、任务、拜师成长与切磋闭环。
- [ ] WM-09～12：AI上下文、非法输出、故障、幂等和冲突。
- [ ] WM-13～17：持久化、旧档兼容、复用视觉和规模边界。
- [ ] WM-18～22：单向边、探索与感知隔离、地图操作、快照乱序与提交后视觉反馈。
