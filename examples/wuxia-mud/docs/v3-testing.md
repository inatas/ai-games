# 武侠示例 v3 测试设计

版本：v3，已确认。框架公共测试保持题材中性；以下用例归武侠示例。

| ID | 场景 | 精确结果 |
|---|---|---|
| CG-01 | 新角色、旧档重复迁移 | 新默认值正确；旧属性/历史保留；重复迁移无事件和奖励 |
| CG-02 | 两门派拜师；已拜师改投 | 同房合法拜入；改投拒绝且无变化 |
| CG-03 | 学基础/门派技能 | 潜能、前置、上限均由服务端校验 |
| CG-04 | 领取→击败恶徒→交付→再领 | 周期递增；每周期经验5/潜能4且只发一次 |
| CG-05 | 普攻与技能 | 伤害公式固定；技能消耗内力；不足时拒绝 |
| CG-06 | 玩家死亡 | 回出生点并恢复，银两最多减1，任务保留、敌人恢复 |
| CG-07 | 同ID重发及两个并发回合 | 只执行一次；过时版本不覆盖新状态 |
| CG-08 | 模型输出伪造数值 | Schema/游戏边界拒绝或忽略，数值只由规则产生 |
| CG-09 | 重启/刷新/新局 | 当前档案恢复；新局重建玩家私有状态 |
| SR-01 | 两账号进入同房 | 双方快照出现对方公开名称，不暴露私有数值 |
| SR-02 | 一方移动或超过在线窗口 | 从同房/在线投影移除 |
| SR-03 | 新局 | realm与另一玩家不重置，新角色重新出现 |
| SR-04 | say后接收者离开/后来者进入 | 仅发送瞬间同房接收者可读 |
| SR-05 | tell | 仅发送者和接收者可读 |
| SR-06 | chat、超长和空白文本 | realm可读；非法文本拒绝且不写入 |
| SR-07 | invite→accept→leave | 队伍关系正确，余一人自动解散 |
| SR-08 | 过期邀请、第五人、跨目标伪造 | 服务端拒绝，无部分关系 |
| SR-09 | 同ID/并发接受 | 单次生效，成员不进入两个队伍 |
| SR-10 | 越权读取/写入 | 非当前scope为403，私聊不泄漏 |
| SR-11 | 捕获AI上下文 | 不含聊天、私聊、无关玩家或整份realm状态 |

单元测试覆盖公式与资格；PostgreSQL集成测试用2～5个账号覆盖事务、幂等、隐私和重启；浏览器测试覆盖档案、战斗、同房玩家、聊天、队伍及窄屏。完整回归继续运行现有WM、D、F用例。
