# 武侠世界 MVP 测试设计

版本：v2，已确认；依据[世界设计](world-mvp.md)及[地图设计](map-presentation.md)。本文件为测试契约；已实现测试和实际执行范围见[验证记录](world-mvp-verification.md)，执行顺序见[实施计划](world-mvp-plan.md)。

## 数据与通用断言

MW0：独立scope，村口，银两20/侠义0/武学1/无师承，hostVersion及memoryVersion为0，奇遇未完成，空背包，寻药任务not_started，已发现仅村口；5名NPC在配置位置。初始化不产生行动事件。每例隔离数据；真实数据库测试只使用随机测试schema。

MW-QUALIFIED：真实执行两次行善后到武馆；MW-PARCEL：接受任务后到林地拾取药包；MW-LEGACY：现有格式角色含历史、师承及已完成奇遇，缺少新增世界字段。历史相关用例通过实际行动构建，不伪造记忆假装经历。

Mock按调用契约分别返回合法answerId、ACCEPT/DEFER、GIFT/GUIDANCE，以及额外奖励字段、未知answerId、超时；不同契约不混用输出。每次成功可变行动版本各+1，失败不改变游戏状态或有效记忆。读取不增版本、不调用模型。

## 用例

| ID | 场景/操作 | 验收结果 |
|---|---|---|
| WM-01 | 加载12房间；另注入重复ID、悬空出口、未知模板、不可达必需地点 | 正常图通过；各非法配置加载失败并定位错误 |
| WM-02 | 村口移至青石街；随后伪造不相邻出口；未拜师尝试进入内室 | 合法移动只改位置/发现/事件版本，不调用模型；非法移动无变化 |
| WM-03 | 查看局部地图及场景；任务前后查看林地 | 未发现远端与药包秘密不泄漏；只有任务active且未拾取时可见药包；读取无模型及版本变化 |
| WM-04 | 在村口对药师交谈/交付；对不存在NPC交谈 | TARGET_NOT_PRESENT；模型0；无任务或物品变化 |
| WM-05 | 接受任务→林地拾取→药铺交付→重复拾取/交付 | 数量依次0→1→0，completed、silver22；重复操作不重复发奖；未知物品拒绝 |
| WM-06 | 完成任务→广场行善两次→武馆拜师ACCEPT→后院挑战 | silver21、virtue2、skill2、master青松道人；位置后院；此段任务/成长流程除拜师外不调用模型 |
| WM-07 | 有师承通过内室出口；低侠义拜师；合法DEFER；低武学挑战 | 出口门槛正确；资格拒绝模型0；DEFER及落败仍提交事件但不改属性 |
| WM-08 | 溪边奇遇合法分支，重复奇遇；在其他房间伪造奇遇 | 奖励和完成标记一次；错误位置不调用模型；开放事项按既有规则关闭 |
| WM-09 | 向曾被帮助的村民交谈，捕获Mock收到的上下文 | 含世界观、当前房间/目标/玩家、真实帮助记录和允许answerId；不含全地图及其他NPC秘密；选中ID由服务端模板展示 |
| WM-10 | 未知answerId或额外silver字段，纠正后仍非法；玩家要求生成奖励 | 非法输出拒绝，无奖励、任务或有效记忆变化；玩家文字不能改变允许结果与Schema |
| WM-11 | 模型超时；提交过程中注入存储失败；快照版本变化 | 无部分状态/记忆；过时快照不能提交；失败后可按协议继续新动作 |
| WM-12 | 移动/拾取/交付同ID重发，丢响应后刷新；同ID改目标；两标签并发 | 原请求只生效一次；更改内容冲突；同scope协调与旧版本拒绝符合框架契约 |
| WM-13 | 重启、登出再登录、另账号尝试读取、主动开新局 | 原位置背包任务恢复；越权不可读；新局回MW0，旧局保留但不能经当前游戏API读写 |
| WM-14 | MW-LEGACY迁移，重复迁移 | 保留全部旧属性及历史，补村口和新表数据一次，不增加奖励/行动版本；既有成功requestId返回原结果 |
| WM-15 | 浏览器完成移动、选NPC、拾取交付及锁门提示；窄屏和键盘操作 | 场景对象/地图/面板与服务器同版本；不存在仅鼠标可触发的必要操作；刷新恢复原请求 |
| WM-16 | 配置一个使用已有模板的新room | 不新增场景组件或背景图即可显示正确对象与出口；地图位置不影响规则相邻性 |
| WM-17 | 独立生成3000房间、每房最多8出口的合成图，查询局部地图 | 返回仅可见两跳范围、最多73个去重节点，不返回整图；记录实际耗时和响应大小，不以此替代生产压测 |
| WM-18 | 经茶馆后院单向返回青石街；尝试原路反向；检查双向出口 | 只有实际配置方向允许移动；SVG箭头和虚实线正确，未定义反向请求拒绝；不同门槛的双向边不错误合并 |
| WM-19 | 已探索茶馆后离开；在服务端改变其NPC状态；查看邻近地图并发起当前NPC判定 | 已探索地理可见，不出现茶馆实时NPC状态；AI输入不自动包含远端变化；浏览器响应和上下文均无秘密字段 |
| WM-20 | 拖动/缩放后移动并刷新；点击远端节点和锁定出口；键盘选出口 | 节点固定坐标保持稳定；视图操作不修改游戏；远端不可瞬移；明确执行后才移动，锁定显示原因；回到当前位置可用 |
| WM-21 | 延迟/乱序返回快照；切新局后返回旧局请求；焦点恢复及刷新失败 | 同scope不被低版本覆盖，跨scope旧响应忽略；地图/场景/背包同次更新；失败标记未同步并禁用变更，可重试，绝不自动新局 |
| WM-22 | 拾取药包、交付、拜师；分别模拟提交成功和失败并刷新视图 | 成功后物品、任务、锁提示来自已提交快照；失败不乐观发奖/解锁；减少动态效果设置生效，必要动作无需hover |

WM-06的银两计算：初始20+任务2-两次行善4+挑战3=21。移动不改银两；版本数量按实际成功动作数断言，不硬套旧五步Demo版本。
