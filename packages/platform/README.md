# 基础平台

独立安装migratePlatform后支持无地图角色、realm公共聊天、角色私聊与队伍关系。SocialPolicy由可信服务端提供局部消息、附近列表、邀请资格和退出回调；默认不启用局部频道。回调在调用者事务中运行，不得等待外部网络。

postWalletEntry提供整数量额、非负余额、钱包行锁和幂等流水。账号资产与realm角色资产隔离；调用方必须先做业务授权，不能把任意记账参数直接映射为用户HTTP接口。青溪银两尚未切换到账本。冻结、转账、真实充值、退款和跨realm账号IM不在当前已实现API中。

本包仅依赖core和AJV，不引用地图/NPC/任务/库存；边界由仓库检查约束。公共表保留mud_*旧名以保护存档。
