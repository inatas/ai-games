# 模型上下文前缀缓存 v1 验收说明

状态：用户已确认并实施。关联[设计](../specs/model-context-cache-v1.md)。

| 用例 | 预期 |
|---|---|
| MC-01 同游戏连续两次不同场景/Schema | 前两条 system 消息字节相同且先于 Schema；动态事实和 Schema 不进入此前前缀 |
| MC-02 世界观与权限 | 世界观在固定游戏指令之后；狼人杀真角色的私有规则仅出现在被授权席位请求中，其他席位和公共历史中没有 |
| MC-03 狼人杀规则去重 | 稳定规则摘要只出现于 system 指令；当前事实仍保留规则版本、事实边界和动态状态 |
| MC-04 DeepSeek 完整用量 | 合法命中、未命中字段进入 `ModelResponse.usage` 和 `model.call.finished.v1`；总输入输出不变 |
| MC-05 缺失与异常字段 | 其他供应商或旧响应保持原用量结构；缺失、负值、非整数或总数不一致的缓存字段不被误报为零命中 |
| MC-06 纠正调用与预算 | 原始消息前缀保持不变，仅末尾追加纠错消息；预算、超限和宿主结果校验维持原行为 |

验证记录（2026-09-24）：MC-01、MC-03、MC-04/05 的定向测试及现有世界观测试先在旧实现上失败，实施后定向 12/12、全仓单元 118/118、`npm run check`、`npm run check:repo` 与 `git diff --check` 通过。MC-02 的既有规则授权回归随单元测试通过；MC-06 的纠正消息行为由既有集成用例覆盖，但本次数据库集成未运行。宿主机缺少 `TEST_DATABASE_URL`，Docker API 返回权限不足；新增事件日志集成用例因此未验证。真实 DeepSeek 缓存命中率未实测，不将其记为通过。
