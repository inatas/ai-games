# 房间制回合框架验收 v1

范围：通用框架、中性测试游戏；不包含具体MOD规则或界面。实现授权见[设计](../specs/turn-based-matches.md)。

- TB-01：非法人数/座位/模型拒绝；部分入座保持waiting；满员原子开局；重复创建/入座幂等，冲突参数拒绝。
- TB-02：顺序发言只能当前席位行动；错误阶段/非法动作拒绝；完成阶段推进一次；MOD决定终局。
- TB-03：sealed先后提交不改变其他席位的可见事实；顺序阶段可见已提交公开发言；私有事件仅授权席位读取。
- TB-04：终局前旁观无私有数据，正常结束后开放复盘；失败/预算中止不揭密；模型上下文不采用终局全知视图。
- TB-05：同room并发tick只调用一次模型；重复runKey、重启、已提交请求不重复行动；不同房间和座位scope隔离。
- TB-06：真实数据库验证最终回滚、阶段版本检查、过期响应、模型失败暂停与显式恢复；失败无有效记忆和游戏事实。
- TB-07：实际捕获ModelAdapter消息检查授权事实；各席位独立模型profile；未知profile、无效Schema、预算超限拒绝或中止。
- TB-08：仅底层表+tb表完成中性游戏，数据库中没有MUD表；依赖检查禁止MUD/房间框架互相引用及底层反向引用。

先运行新增行为测试并记录失败，再实现。单元测试、真实PostgreSQL、既有回归、构建和真实模型分开记录；不以Mock或数据库模拟器冒充真实PostgreSQL。

## 抢占v2验收（已确认并有可执行测试）

依据[抢占设计](../specs/turn-based-interrupts.md)，使用中性游戏。

- TB-09：普通模型等待时另一lane可独立插队，不要求轮到该席位；禁止阶段/越权席位拒绝；公开DTO不暴露插队actors。相同lane并发共享请求，不同lane并行。
- TB-10：真实数据库中抢占先提交，迟到普通响应被拒绝且无有效记忆；反向顺序保留已提交事实，旧epoch插队不得误套新阶段。
- TB-11：两个并发插队仅一个在旧epoch生效，重复请求重放；后续允许插队须新请求，旧任务失败不阻断新阶段。
- TB-12：事务故障注入验证状态、事件、请求结果、有效记忆整体回滚，模型等待期间不持锁；捕获实际模型输入证明lane不越权读其他席位。
- TB-13：pass无公共事件、仍计预算；周期判断不阻塞普通行动，预算中止不揭密；网络失败blocked，不自动重试。
- TB-14：登记后/提交后重启、旧租约未到期/已到期、关闭登记竞态不重复行动；失效scope租约未结束不得并发复用；数据库备份恢复与MUD回归单独记录。

## 有界模型网络重试 v1.1（已实施，真实模型故障待复核）

依据[需求030](../../.agents/note/030-bounded-model-network-retry.md)。`packages/core/tests/model-network-retry.test.ts` 与 `tests/integration/model-network-retry.test.ts` 已覆盖下列关键边界；2026-09-26 隔离 PostgreSQL 全套 `npm test` 262/262 通过。真实供应商断网与账单复核未运行。

- MR-01：`network` 失败且同一请求、阶段、租约及截止有效，最多补发两次；第三次实际调用成功也仅提交一次游戏动作，三个 attempt 的失败、完成及裁判结果可追踪。
- MR-02：两次网络重试分别在前次确定失败并持久记日志后，等待配置的第一、第二间隔；狼人杀配置分别至少 1 秒、3 秒，各加 0–500 毫秒随机等待。不会立即重发或同时在途。退避中截止、阶段失效或租约失效，不再调用。
- MR-03：网络重试和最多一次格式纠正共享 3 次物理调用额度；第 3 次输出无效不得发第 4 次。格式纠正后若发生可重试网络失败，也仅能使用剩余额度。
- MR-04：HTTP 错误、响应错误、业务拒绝、取消、总超时及剩余时间不足都不补发；原阶段截止与默认结算不变。
- MR-05：同 profile 集中断线限制并发重试并开启短时熔断，不跨 profile 影响；重启、两宿主竞争和迟到响应都不能重复调用或覆盖已提交结果。
- MR-06：无响应的尝试只记未知 usage；收到真实供应商 usage 的尝试逐次计入，不推断首次失败一定免费。
