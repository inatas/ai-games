# 房间制回合框架验收 v1

范围：通用框架、中性测试游戏；不包含狼人杀规则或界面。实现授权见[设计](../specs/turn-based-matches.md)。

- TB-01：非法人数/座位/模型拒绝；部分入座保持waiting；满员原子开局；重复创建/入座幂等，冲突参数拒绝。
- TB-02：顺序发言只能当前席位行动；错误阶段/非法动作拒绝；完成阶段推进一次；MOD决定终局。
- TB-03：sealed先后提交不改变其他席位的可见事实；顺序阶段可见已提交公开发言；私有事件仅授权席位读取。
- TB-04：终局前旁观无私有数据，正常结束后开放复盘；失败/预算中止不揭密；模型上下文不采用终局全知视图。
- TB-05：同room并发tick只调用一次模型；重复runKey、重启、已提交请求不重复行动；不同房间和座位scope隔离。
- TB-06：真实数据库验证最终回滚、阶段版本检查、过期响应、模型失败暂停与显式恢复；失败无有效记忆和游戏事实。
- TB-07：实际捕获ModelAdapter消息检查授权事实；各席位独立模型profile；未知profile、无效Schema、预算超限拒绝或中止。
- TB-08：仅底层表+tb表完成中性游戏，数据库中没有MUD表；依赖检查禁止MUD/房间框架互相引用及底层反向引用。

先运行新增行为测试并记录失败，再实现。单元测试、真实PostgreSQL、既有回归、构建和真实模型分开记录；不以Mock或数据库模拟器冒充真实PostgreSQL。
