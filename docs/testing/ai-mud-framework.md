# AI MUD框架验收契约

版本v1，已确认；依据[设计](../specs/ai-mud-framework.md)。数据库行为测试使用隔离随机schema。

NPC/地图拆分补充：map-npc单测验证地图独立校验与投影、无出生位置NPC、重复身份及悬空出生位置拒绝；注册测试覆盖独立NPC契约。沿用MF-05/12/14数据库回归验证共享位置、旧档迁移和AI等待期间移动导致冲突。

| ID | 行为与预期 |
|---|---|
| MF-01 | 通用包不导入MOD；通用UI无门派/内力字段；全部跨包导入经过公共入口 |
| MF-02 | 同一引擎装配青溪镇与中性MOD；属性、公式和世界观按MOD分别生效 |
| MF-03 | 缺入口、悬空引用、重复ID、未知版本启动失败，无半初始化realm |
| MF-04 | 同MOD两个realm：房间状态、NPC、聊天、队伍与记忆互不泄漏 |
| MF-05 | 同realm两角色读取同一公共NPC位置；修改后两者一致，个人关系仍私有 |
| MF-06 | 伪造角色/realm/目标、旧角色或跨realm邀请均拒绝且无部分写入 |
| MF-07 | 心跳、过期、多会话登出正确；游戏读取不改变角色/记忆版本 |
| MF-08 | 双向邀请、并发接受、第五人入队、并发离队无死锁或超员，单角色至多一队 |
| MF-09 | 两人共享任务、后来入队、离队、解散严格按冻结名单和归属执行 |
| MF-10 | 并发完成/领奖、丢响应重发、改内容重发仅一次奖励；注入故障全部回滚 |
| MF-11 | AI等待时公共NPC移动/任务被完成，旧提案冲突，不能覆盖新状态 |
| MF-12 | 旧档两次迁移保留属性/历史/请求结果；NPC冲突报告可审阅；真实恢复演练通过 |
| MF-13 | Web不依赖武侠字段，切换MOD的场景/属性/动作正确，窄屏和键盘可操作 |
| MF-14 | 捕获模型请求：有正确世界观和可见事实，无他人私聊、私有任务及隐藏NPC状态 |
| MF-15 | 现有框架和青溪镇回归通过；新局清理旧队伍关系且不重置realm |

通用用例放packages/mud-core/tests和tests/integration，使用中性夹具；青溪镇规则、伤害和任务奖励断言放mods/qingxi/tests。末世题材不作为本次必须交付游戏。每个验收项记录实际命令、结果和未覆盖边界，不以构建通过代替数据库行为验证。
