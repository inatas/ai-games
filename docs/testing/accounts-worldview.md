## 数据与环境

每组使用独立PostgreSQL随机schema、可控时钟、中性宿主初始化回调和ScriptedModel。用户alice、bob使用仅限隔离测试库的固定测试密码；浏览器测试使用临时生成的qa账号；日志不得输出凭据。中性宿主初始counter=0，行动后+1。世界A/v1正文“世界处于和平时期”，A/v2正文“世界进入冬季”，B/v1为独立背景。失败回调在写入宿主状态后主动抛错。测试结束只清理自己创建的schema。

## 账号、会话与档案

| ID | 操作与前置条件 | 预期 |
|---|---|---|
| U-01 | 新用户名和有效密码提交 | 只创建一个用户、当前scope及初始状态；Cookie不暴露给JS，响应无令牌 |
| U-02 | 已有账号正确密码重登，先执行一次行动 | scope不变，counter=1，历史保留 |
| U-03 | 已有账号错误密码；空白/超限输入 | 登录失败，不重设密码、不创建scope，无原凭据输出 |
| U-04 | 同名大小写/首尾空白并发注册，同密码与不同密码各测 | 规范用户名唯一；只能用最终有效密码登录，无孤儿当前档案 |
| U-05 | 关闭页面再打开；重建服务实例 | 有效Cookie恢复原用户及scope，无需再次输入密码 |
| U-06 | 可控时钟推进，验证活跃续期及30天无活动过期 | 续期正确；到期401；重登仍是原存档 |
| U-07 | 退出及重复退出，再重放旧Cookie | 退出幂等，旧会话失效；其他设备会话继续有效 |
| U-08 | bob请求alice的scope；伪造/缺失Cookie | 无权读取或执行，无任何状态变化 |
| U-09 | 跨源或缺Origin写请求；反复错误登录 | 拒绝写入；达到阈值429，限流窗口恢复，无凭据泄露 |
| U-10 | 新局成功，随后重登 | 当前scope只切换一次，旧档保留、不可继续操作 |
| U-11 | 新局初始化中途失败 | 当前scope及原状态不变，新scope和初始化写入回滚 |
| U-12 | 重发同requestId；不同requestId并发基于同旧scope | 同请求返回同结果；竞争者冲突，不创建多局 |
| U-13 | 同requestId改载荷 | 幂等冲突，不切换档案 |
| U-14 | 行动登记与新局切换并发；行动仍processing | 无授权竞态；待处理时拒绝新局，完成或过期恢复后可切换 |
| U-15 | 登录/恢复/读取失败及401的页面流程 | 加载期间无新局入口；失败可重试；401回登录，右上角登出仅登录时可见 |
| U-16 | alice有待处理请求，退出后bob登录 | 不重发alice请求，bob仅加载自己档案 |
| U-17 | 升级含游客数据数据库 | 旧数据保留，游客令牌不能换取账号身份，显示未迁移说明 |

## 世界观

| ID | 操作与前置条件 | 预期 |
|---|---|---|
| W-01 | 中性宿主连续两个assessment，第二次发生结构纠正 | 每次调用均有完整同版本世界观，位置固定 |
| W-02 | 世界观与必需内容超预算；增加大量可选历史 | 超预算调用次数0、状态不变；可选历史不能挤掉世界观 |
| W-03 | 输入要求忽略世界观并修改数值 | 世界观和协议仍存在；非法提案被校验拒绝，宿主规则有效 |
| W-04 | 空文件、超16KiB、无效编码、缺配置或同版本不同正文 | 明确配置错误，不静默回退空世界观 |
| W-05 | v1旧局，加载v2后重登并新建一局 | 原局仍v1，新局v2；重启后版本保持 |
| W-06 | 两个scope绑定不同世界观 | 模型调用各带正确快照，记录版本及摘要，无串用 |
| W-07 | recordMemory动作 | 不调用模型、不改变世界观版本 |
| W-08 | 模型成功/失败/纠正 | 调用记录均可追溯所用世界观版本与摘要 |

## 新角色失败反馈与恢复

1. 有 processing 行动时开启新角色，接口返回 `SCOPE_BUSY`，页面显示该原因且不会丢弃可重试请求。
2. 当前 scope 已变化时开启新角色，接口返回 `STATE_CONFLICT`，页面清理旧请求并要求刷新当前档案。
3. 成功开启新角色后，页面使用响应中的 `currentScopeId` 读取新角色；重复相同 requestId 不产生第二个 scope。
4. 确认弹层点击“取消”后立即关闭，不因本地暂存请求再次自动打开。
