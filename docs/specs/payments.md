# 可选平台支付集成边界

真实充值尚未接入。钱包账本提供服务端记账原语，不表示存在可对外使用的支付功能。

支付模块属于平台可选集成，与地图、NPC、任务无依赖；MOD不能确认支付成功或任意增发平台资产。

正式接入前须确认渠道及商户账号、金额币种、商品价格、入账币种、兑换和退款规则。服务端创建订单并固化金额；验证渠道签名和订单身份、金额、币种及终态；同一渠道交易只能入账一次。浏览器跳转成功不是到账证据。

已验证支付在短事务中更新订单和账号钱包，渠道网络调用不占数据库锁。游戏兑换由单独授权服务协调平台扣款与权益发放，跨事务边界须有可恢复状态。退款采用反向流水及权益撤销政策，不删除原流水。对账、回调重放、退款重放、金额不符和伪造签名须独立验收。

本轮不建立模拟充值路由，不声称支持真实收费；账号钱包与realm角色钱包已在基础层区分。好友IM、未读、推送和支付渠道属于后续明确产品需求，不与三层代码迁移混为同一验收。
