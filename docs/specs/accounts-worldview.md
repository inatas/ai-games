# 公共账号、持续档案与世界观配置

版本：v1，用户已确认并授权实现；实际验证状态见[验证记录](../verification.md)。关联需求：009、010；验收见[测试设计](../testing/accounts-worldview.md)。

## 目标与模块边界

框架增加公共账号与会话、当前游戏档案、世界观配置能力，任意题材宿主均可接入。新增`packages/identity`负责账号、会话与档案服务契约，存储实现放在`packages/storage`，公共HTTP路由由`apps/server`装配。core只接收已授权scope和世界观快照，不依赖HTTP或账号密码。公共模块不包含武侠数值、角色初始化或剧情判断。

账号与scope的授权由公共模块执行；宿主通过事务回调初始化游戏状态。现有五层Harness及游戏规则边界不变。武侠界面只接入公共能力，世界观具体文字属于游戏配置，加载、版本关联和注入机制属于框架。

## 登录与长期会话

登录页统一输入用户名和密码，提示“账号不存在时将自动创建”。用户名去首尾空白、统一大小写，允许3–32位ASCII字母、数字、下划线；密码8–128字符，不去空白。首次输入即提交：用户不存在则以此密码创建并登录；已存在则必须校验原密码，错误不得重设密码或新建档案。MVP不增加注册页、找回密码、邮箱验证或第三方登录。

密码使用独立随机盐和scrypt派生后保存，不存明文。会话使用随机令牌，数据库仅存摘要；通过HttpOnly、SameSite=Lax、Path=/ Cookie保存，部署HTTPS时启用Secure。本地HTTP开发允许关闭Secure。默认记住登录，30天无活动失效、每次有效请求续期；退出立即撤销当前会话并清Cookie，其他设备不退出。重启应用后会话仍有效。

所有写接口校验同源Origin；浏览器写请求必须提供合法Origin，非浏览器客户端需使用单独明确的接入策略，MVP不开放。登录限流采用每IP及规范化用户名组合15分钟10次失败，同时设每IP每15分钟100次失败上限（并发在途尝试先占额度，成功释放）；不记录密码或令牌。登录失败返回统一凭据错误。并发注册依赖用户名唯一约束，冲突后校验实际已创建账号密码，不能绕过验证。

## 每用户一个当前档案

一个用户在当前部署中只有一个当前scope。首次成功登录在同一事务中创建账号所需记录、scope、宿主初始状态及初始记忆，并关联当前档案。既有用户再次登录、刷新页面或重启服务，只加载原scope，不创建新局。游戏档案没有自动过期或日常重置。

“开启一段新的江湖”需明确确认。请求携带唯一requestId与expectedCurrentScopeId；公共服务锁定用户行，校验当前scope，原子创建新scope、执行宿主初始化并切换指针。失败全部回滚；重复requestId返回同一新scope；不同请求若基于旧指针则冲突，不连续创建多局。处理中的旧局行动存在时拒绝切换，先等待完成或恢复过期请求。旧档案保留为历史但不再允许游戏读写；本期不提供历史切换或删除。

游戏行动登记与新局切换必须共享用户→scope的锁序并在登记事务内验证当前档案，避免“授权后被切换”的竞态。不得仅在HTTP前置检查一次。只有当前scope可提交行动或读取游戏；不同账号禁止互访。

仅支持账号会话，不保留游客凭据、提示或迁移入口。开发库允许按破坏性升级政策重建。

## 公共接口与数据

| 接口 | 契约 |
|---|---|
| POST /api/auth/login | username、password；登录或自动注册，设置Cookie，返回用户及currentScopeId，不返回令牌 |
| GET /api/auth/session | 恢复会话，返回用户、currentScopeId；未登录401 |
| POST /api/auth/logout | 撤销当前会话，清Cookie；重复退出成功 |
| POST /api/game/current/reset | requestId、expectedCurrentScopeId；原子开启新局 |

新增fw_users（唯一规范用户名、密码派生值/盐、current_scope_id）、fw_sessions（令牌摘要、user_id、expires_at）、fw_game_resets（user_id/request_id唯一、完整请求中的旧scope字段、旧新scope关联）、fw_worldviews（world_id/version唯一、正文、内容摘要）。scope增加世界观版本外键。账号表和档案初始化由公共迁移与宿主回调协调；不提供旧数据库升级路径。

公共档案服务通过login确保当前档案存在，提供reset与authorizeCurrent/行动登记事务契约；宿主提供initialize(tx, scopeId)回调，仅初始化题材数据和初始记忆，不拥有账号、Cookie或当前档案指针。

## 页面状态

启动先检查会话，加载过程中不显示新建入口。未登录显示统一登录/自动注册表单；登录后读取当前档案。右上角显示用户名和“登出”链接。读取失败显示重试，不能自动新建。401返回登录页，保留服务端存档；403/冲突提示重新加载当前档案。

退出清除客户端内存和待处理请求，不删除服务端档案；在途行动可能已提交，下次登录读取真实状态。待处理请求按用户和scope绑定，不复用其他用户的旧请求。新局确认提示旧局将结束且本期不能切回。默认长期会话无需每次输入密码。

## 世界观配置与模型上下文

管理员通过服务端配置文件WORLD.md提供基础世界观，配套worldId和version；路径由部署配置指定，不能由玩家请求指定。不是读取仓库AGENTS.md作为剧情：AGENTS.md仍是开发规范。公共加载器校验正文非空、UTF-8、最大16KiB，并计算SHA-256摘要。相同worldId/version内容不同则拒绝启动；版本不可变。

新scope绑定启动配置的世界观版本，旧scope继续使用已保存版本。编辑文件并提升version、重启后只影响新局，避免持续档案中基础设定悄然改变。MVP不提供在线编辑器、玩家自定义世界观或旧档案批量升级。

每个assessment请求从scope读取世界观快照；首次模型调用及结构纠正调用都包含完整WORLDVIEW系统消息。顺序为框架协议、世界观、宿主任务与输出Schema、当前事实、必需记忆、可选历史、玩家输入。世界观规定背景，不能授予工具权限、绕过Schema或替代游戏硬规则；冲突时协议和宿主当前事实优先。

世界观属于必需上下文，计入预算，不允许截断、摘要或因历史过长而移除；超限在调用前失败，不产生游戏变化。无AI的recordMemory动作不调用模型。模型调用记录增加worldId/version/摘要用于追溯，不保存密码或会话。框架测试使用中性世界观，武侠文字仅在示例配置中。
